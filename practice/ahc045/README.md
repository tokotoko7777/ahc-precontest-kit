# AHC045 - 矩形中心で分割し、MST問い合わせで辺を確定する

## この問題の二つの仕事

この問題では、次の二つを同時に決めます。

1. 都市を指定サイズのグループへ分ける。
2. 各グループ内を短い木で結ぶ。

真の座標は分かりませんが、各都市が入る矩形は分かります。まず矩形中心を推定座標としてグループを作り、その後のMST問い合わせを主に「辺を正確に選ぶ」ために使います。

コードでは小数を避けるため、中心座標そのものではなく

```text
x = lx + rx
y = ly + ry
```

という中心の2倍を使います。距離の大小関係は変わりません。

## 1. k-d木風にグループを作る

全都市と全グループから始め、再帰的に二分します。

1. グループをサイズの大きい順に見て、必要都市数が均等になるよう左右へ振り分ける。
2. 都市の推定座標の広がりが大きい軸を選ぶ。
3. その軸で都市を整列し、左側グループが必要とする個数で切る。
4. 左右を同様に再帰分割する。

グループが一つになったら、残った都市をそのグループへ割り当てます。これだけで各グループの個数制約を常に満たせます。

## 2. 都市交換で丸くする

k-d分割後、異なる2グループの都市を交換します。評価値は各グループ内の中心からの二乗距離和です。

```text
sum(|p|^2) - |sum(p)|^2 / group_size
```

この式なら、座標和と二乗和を持つだけで交換差分を `O(1)` で計算できます。

全く無関係な都市同士を選ぶだけでは改善候補に当たりにくいため、各都市について推定座標で近い24都市を先に求めます。10回中9回はこの近傍から交換相手を選び、残り1回は全都市から選びます。評価が改善する交換だけを採用します。

## 3. 問い合わせをそのまま合法な木にする

グループ全体が問い合わせ上限 `L` 以下なら、全都市を一度に問い合わせるだけで真のMSTが得られます。

大きいグループでは、次の形で分割します。

1. 既に接続済みの都市から、未接続都市に最も近い `anchor` を選ぶ。
2. その未接続都市の周囲から最大 `L-1` 都市を集める。
3. `anchor` と新しい都市だけを問い合わせる。
4. 返されたMST辺を全て採用し、新しい都市を接続済みにする。

各問い合わせは、以前の木と `anchor` 一頂点だけを共有します。返答は問い合わせ集合上の木なので、それらを合併しても閉路はできず、最後はグループ全体を結ぶちょうど `G-1` 辺の木になります。

必要問い合わせ数はグループごとに

```text
ceil((G - 1) / (L - 1))
```

です。`L>=3` なのでこれは `floor(G/2)` 以下であり、全グループ合計でも `N/2=400` を超えません。

## 問い合わせを使わない安全弁

矩形幅 `W` が小さいときは推定中心が比較的正確です。一方、大きなグループを多数の問い合わせへ分割すると、問い合わせ間の境界が全体MSTを邪魔する場合があります。

そこで次を全て満たす場合だけ、問い合わせをせず、推定中心上の全体MSTを使います。

- `W <= 820`
- グループ数が2～35
- `G <= L` の小グループが全体の35%以下

それ以外では問い合わせを使います。これは「観測が有利とは限らない場合の単純なフォールバック」です。閾値はREADME末尾の公式ケース比較で確認した値なので、別分布へ流用する際は再調整してください。

## 合法になる理由

- k-d分割と交換は都市数を変えないため、各グループは常に指定サイズです。
- 都市は最初に一度だけ割り当て、交換も一対一なので重複・欠落しません。
- 問い合わせは2～`L`個の相異なる都市だけを出します。
- 各問い合わせ木は既存部分と一頂点だけを共有するため、合併後も木です。
- 問い合わせを使わない場合はPrim法でグループ内の全頂点を結ぶ木を作ります。
- 問い合わせ数は最大397回の実測で、上限400回以下です。

## 使い方

この問題は対話形式です。通常の入力リダイレクトだけでは、問い合わせへの返答を受け取れません。提出時は `main.cpp` 単体で動き、ローカル確認では公式testerを間に入れます。

```bash
g++ -std=c++20 -O2 -pipe -Wall -Wextra -Wshadow main.cpp -o main

# 公式toolsディレクトリで実行する例
./target/release/tester /absolute/path/to/main < in/0000.txt > out.txt
```

比較用の単純基準版も同じソースから作れます。

```bash
# 矩形中心をx順に並べて分割し、中心距離のPrim木を出すだけ
g++ -std=c++20 -O2 -DAHC045_BASELINE main.cpp -o main-baseline

# 交換回数を50万回から2万回へ減らす
g++ -std=c++20 -O2 -DLOCAL_SHORT_TIME main.cpp -o main-short
```

## 計算量

- 近傍24都市の前計算: `O(N^2 log 24)`
- 交換探索: 1反復 `O(1)`、通常50万回
- 推定MST: 各グループで `O(G^2)`
- 問い合わせ用の局所集合構築: 素直な全走査。`N=800` では十分小さい
