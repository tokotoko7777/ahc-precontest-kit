# AHC016 practice: Graphorean

提出用の [main.cpp](./main.cpp) だけで動く、C++17 の対話型ソルバです。

- 公式問題文: <https://atcoder.jp/contests/ahc016/tasks/ahc016_a>
- 公式ローカルツール: <https://img.atcoder.jp/ahc016/d5f3c281.zip>

## 問題を一言で

最初に `M` 個のグラフを自分で作ります。その後、ジャッジはそのどれかを選び、頂点番号をシャッフルし、各辺の有無を確率 `epsilon` で反転して送ってきます。これを100回、どのグラフが元だったか当てます。

誤答数を `E`、こちらが選んだ頂点数を `N` とすると、1ケースの得点は次です。

```text
round(10^9 * 0.9^E / N)
```

したがって、単に `N=100` にして正答率だけを上げるのではなく、簡単なケースでは `N` を小さくする必要があります。

## 解法の中心

### 1. ノイズがないとき

`G_k` の辺数をちょうど `k` 本にします。頂点番号を入れ替えても辺数は変わらないので、受信グラフの辺数を数えるだけで必ず復号できます。

### 2. ノイズがあるとき

まず、5頂点の小さな「色付きグラフ」を考えます。

- 各頂点には「同じ種類の頂点同士を全結合するか」という1 bitを持たせる
- 各頂点ペアには「2種類の間を全結合するか」という1 bitを持たせる

合計は `5 + 5C2 = 15` bitです。同じグラフを頂点名だけ変えて重複して数えないよう、5!通りの並べ替えの最小値を代表にします。これで候補は544個になり、最大の `M=100` に十分です。

次に、小グラフの各頂点を `D` 個の同じ頂点へ膨らませます。最終的な頂点数は `N=5D` です。1 bitの情報が多数の辺へ繰り返されるので、多少の辺反転では構造が消えません。

`D` は次で決め、3〜20へ収めています。

```text
D = round(0.49 * log2(M) / (1 - 2*epsilon)^2)
```

これは理論的な最適値ではなく、公式generatorの公開seedで得点との釣り合いを測って決めた値です。

### 3. 頂点番号に依存しない特徴を比べる

頂点番号は失われるため、隣接行列をそのまま比較できません。代わりに、並べ替えても変わらない次の量を使います。

- ソートした次数列
- 各頂点から見た、隣接頂点の平均次数
- 中心化した次数を隣接行列で1回伝播した値
- 全頂点ペアの共通近傍数
- 全頂点ペアの隣接行どうしの相違数
- 相違数などを、頂点ペア自身が辺か非辺かに分けた累積分布

各符号グラフへプログラム内で60回ノイズを加え、特徴ごとの平均と分散を作ります。問い合わせでは、受信グラフの特徴が最も近い符号グラフを答えます。外部モデルや学習済みデータは使いません。

## 処理の流れ

```text
M, epsilon を読む
  ├─ epsilon = 0: 辺数だけで符号化・復号
  └─ epsilon > 0
       5頂点の候補544個を列挙
       ↓
       特徴が互いに遠いM個を選ぶ
       ↓
       各頂点をD個へ冗長化して出力
       ↓
       ノイズ付き特徴の平均・分散を自己生成
       ↓
       100問い合わせを最近傍復号
```

### ビルド検査

- `-Wall -Wextra -Wshadow -Wconversion -pedantic`: 警告なし
- AddressSanitizer + UndefinedBehaviorSanitizer: seed 0000, 0003, 0096で異常なし
- 公式testerが全出力について `4 <= N <= 100`、文字列長、予測範囲、100回の対話完了を確認

## 計算量

`N <= 100`, `M <= 100` なので、定数上限を意識した全列挙を使っています。

- 5頂点候補の列挙: `2^15 * 5!`（小さい定数）
- 1グラフの特徴計算: おおむね `O(N^2 log N)`
- 問い合わせ1回の復号: `O(MN^2)`
- 参照特徴の保存: `O(MN^2)`

隣接行の比較は、100 bitを64 bit整数2個へ詰め、`popcount`で処理しています。

## 読み方と再利用できる部分

初心者が追うなら、次の順に読むと楽です。

1. `solve_without_noise`: 一番単純な符号化
2. `expand`: 小さい情報を繰り返して頑丈にする方法
3. `make_features`: 頂点番号に依存しない比較方法
4. `clean_distance` と farthest-point sampling: 似すぎた候補を避ける方法
5. `means`, `variances`: 自分でノイズ例を作って復号器を校正する方法

別問題へ切り出せる候補は次です。

- `Rng`: 小さな高速乱数
- 「全順列の最小表現」による小構造の正規化
- farthest-point sampling（単体版は `library/farthest-point-sampling.hpp`）
- permutation-invariant graph features
- Monte Carloで作る平均・分散つき最近傍分類器

提出用 `main.cpp` にも必要部分を直接含めています。候補選択だけ使いたい場合は、
`library/farthest-point-sampling.hpp` を自分のコードへ貼り付けられます。
