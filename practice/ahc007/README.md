# AHC007 practice

公式問題: [A - Online MST](https://atcoder.jp/contests/ahc007/tasks/ahc007_a)

`main.cpp` だけで提出できる、過去AHCを使ったライブラリ実戦例です。

## 使用したパーツ

- `Dsu`

パーツはローカルヘッダとして参照せず、`main.cpp` の上部へ直接貼っています。

## 独自解法

未公開辺の長さを、問題の生成分布から得られる期待値 `2 × 幾何距離` で予測します。
現在辺を採用済み辺へ加えないまま、未来辺を予測長の短い順にUnion-Findへ追加し、
現在辺の両端が初めてつながる長さを代替コストとします。

- 現在辺が代替コスト以下なら採用
- 未来だけでは両端がつながらないなら必ず採用
- すでに採用済み辺で両端がつながっていれば不採用

後ろから考えると、捨てた辺の両端は最終的に後続の採用辺でつながるため、入力グラフが
連結なら最終結果も連結になります。
