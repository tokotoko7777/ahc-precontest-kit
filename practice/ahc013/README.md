# AHC013 practice

公式問題: [A - Server Room](https://atcoder.jp/contests/ahc013/tasks/ahc013_a)

`main.cpp` だけで提出できる、移動後に交差しない直線配線を作る練習例です。

## 問題の要点

盤面には種類付きコンピュータが各100台あります。先に隣接空cellへの移動を行い、その後に
同じ行・列で見通せる2台をケーブル接続します。移動数＋接続数は `100*K` 以下です。

同じclusterに同種を集めると加点、異種が混ざると減点です。また、ケーブル同士は交差
できません。この実装は同種間だけを接続し、負点を構造上発生させません。

## 解法

### 1. 安全な小移動だけ試す

各コンピュータから上下左右へ見て、最初にある同種コンピュータの本数を数えます。隣の
空cellへ1歩動かすことでこの本数が増える場合だけ移動します。移動上限を
`0, 5, 10, 20, 30, 40` と変えた案をすべて作るため、「動かさない方が良かった」入力でも
必ず移動なし案へ戻れます。

### 2. 接続候補を列挙する

各行・列にあるコンピュータを順番に見ます。間に別コンピュータがない隣り合う2台が同種
なら候補辺です。この列挙方法だけで「ケーブルの途中にコンピュータがある」違反を防げます。

### 3. DSUで大きいclusterを優先する

大きさ `A`, `B` の同種clusterを結ぶと、同種pairはちょうど `A*B` 増えます。毎回この増分が
大きい候補を選び、同点付近では短い線優先・長い線優先・種類優先など複数順序を試します。

ケーブルの内部cellを1次元配列に記録し、新しいケーブルを置く前に全内部cellが空かを確認
します。採用済みcluster内の辺はDSUで飛ばします。最後に全案の正確なcluster得点を比べ、
最良の移動列と接続列だけを出力します。

## 読む時の目印

- `visible_same_neighbors`: 4方向の最初のコンピュータを見る
- `make_helpful_moves`: 同種の見通しが増える1歩移動
- `make_visible_same_type_edges`: 違反しない初期接続候補
- `cable_is_free`: ケーブル交差の検査
- `connect_greedily`: DSUの `size(A)*size(B)` による接続

## 計算量

コンピュータ数を `C=100K`、候補辺数を `E` とすると、接続構築は単純実装でおよそ
`O(C*E*N)`です。公式最大でも `C=500`, `N=48` なので、候補を全pairでなく各行・列の
隣接コンピュータだけへ制限すれば十分高速です。

## 公式ローカルツールでの確認

[公式ローカルツール](https://img.atcoder.jp/ahc013/a42302b3af.zip)のseed 0〜99を
採点しました。

- 全100ケースで移動・配線とも合法
- 平均得点: 1,801.56
- 最小得点: 360
- 最大得点: 5,302
- 種類数別平均: `K=2: 4,167.20`, `K=3: 1,596.32`,
  `K=4: 833.88`, `K=5: 608.84`
- seed 0〜9では移動なし平均965.5点、複数移動案の比較後平均2,047.7点
  （約112%改善）
- solverと公式採点を合わせても100ケースで約5秒

`-Wall -Wextra -Wshadow -pedantic` で警告なしです。ASan・UBSanを同時に有効にした
seed 0（`K=2`）とseed 3（`K=5`）も完走し、公式ビジュアライザで合法でした。

## 注意

- 多段移動や異種を一時的に混ぜる戦略は使わない、安全寄りの基準解です。
- 同じコンピュータを端点にする複数ケーブルは公式に許可されています。
- 研究資料の「合法な接続構築器を複数の優先順で比較する」考え方を基にした独自C++実装で、
  第三者コードの転載ではありません。
