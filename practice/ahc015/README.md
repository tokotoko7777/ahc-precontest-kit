**実験PR・マージ保留。448への増量は90ケースのscoreで旧384を上回らず、不採用です。**

[公式問題 Halloween Candy](https://atcoder.jp/contests/ahc015/tasks/ahc015_a)の実戦例です。
`main.cpp`には共通ヘッダを展開済みで、提出はこの1ファイルだけです。
[使用例の原本](../../examples/search/ahc015_common_rollout.cpp)との完全一致をCIで検査します。

## 問題と解法

10×10盤面へ3種類の飴が100個入ります。味の順序は最初から分かりますが、
配置順位はそのターンまで分かりません。各ターンにF/B/L/Rの1方向へ傾け、
最後の同色連結成分の大きさの二乗和を大きくします。

今の4方向を、同じ未来の配置シナリオ集合で最後まで仮実行します。
未来の自分の操作には、既存ベンチマークと同じ「現在の味×次の味」の固定方策を使います。
共有版の比較で、方策・盤面操作・最終評価は変えていません。

`CoalescedRollout`は同じ段階で盤面が完全一致した候補をまとめ、
残りの共通シナリオを1回だけ進めます。hash衝突や統計的な枝刈りはありません。
同じサンプル数なら、共有を切った全評価と各候補の評価・最終出力が一致します。
型・遷移・等価判定を渡す部品なので、AHC015だけの特例ではありません。

## 編集箇所

| 場所 | TODOで書く内容・返すもの |
|---|---|
| `Board`・`State` | 仮実行に必要な全情報。時刻は全候補で同じ段階を使う |
| `generate_actions` | 比較する合法な最初の1手を、同点時の優先順で返す |
| `generate_scenario` | 未知の配置順位だけを1本sampleして返す。未来の実入力は読まない |
| `tilt_board`・`place_by_rank` | 問題の正確な状態遷移 |
| `rule_direction` | 未来の自分の行動を決める方策 |
| `component_square_sum` | 最終評価値。全Actionで分母が同じなので公式得点の分子を返す |
| `initial_boards` | 各Actionを1回反映した仮状態。Scenarioに依存しないので1ターンに1回だけ作る |
| `advance`ラムダ | 共通Scenarioのstep番を使い、仮状態を1段進める |
| `shared.evaluate` | 各Actionに対応する最終評価の列を受け取る。順序はinitialと同じ |
| 入出力 | 1ターン分の配置を読み、選んだActionを反映して出力・flush |

共通ライブラリが候補の合流管理・代表の選択・残り計算の共有・scoreの対応付けを担当します。
`CommonScenarioRolloutRunner`は共通未来生成・平均・最良Action選択を担当します。

別問題への穴埋めは[共有rolloutフォーマット](../../template/search/coalesced-monte-carlo.cpp)が入口です。
共有に必要な等価判定・遷移・最終評価の空関数を置いています。
「同じ未来になる」と判断できなければ等価判定をfalseにして使えます。
外部の隠れた乱数や副作用に依存する遷移は共有できません。
等価判定は1段O(候補数²)なので、数個の候補を比較する用途向けです。

## コンパイルと設定

```sh
g++ -std=c++17 -O2 -DNDEBUG main.cpp -o main
# 共有だけOFF：同じサンプル数なら得点・出力が一致する
g++ -std=c++17 -O2 -DNDEBUG -DAHC015_MERGE=0 main.cpp -o unmerged
# 従来のActionごとの独立実行（共通乱数は使う）
g++ -std=c++17 -O2 -DNDEBUG -DAHC015_CLASSIC=1 main.cpp -o classic
# サンプル数を変更
g++ -std=c++17 -O2 -DNDEBUG -DAHC015_SAMPLES=256 main.cpp -o smaller
```

この実験の設定は448サンプル/ターンです。時間は環境依存なので、AtCoderでの2秒以内を保証しません。
100ターン目も形式を揃えるため1文字出力します。
各手番の乱数seedを固定し、サンプル数を変えてもその手番の未来列の先頭を揃えています。
使うのは固定seedと現在の手番だけで、未観測の配置順位ではありません。

## 実問題スコアによる検証

共通処理の高速化、時間内のサンプル数増加、その結果の公式scoreを
[比較レポート](../../benchmarks/AHC015_COALESCED_REPORT.md)で分けて記録します。
公式配布入力を1ターンずつ渡す対話ハーネスを使い、出力・flush後まで次の入力を送りません。
採点は公式visualizerと独立した盤面再生の両方で照合します。

以前のpracticeは「最大30手の先読み＋毎手4方向の貪欲評価」という別解法でした。
旧実装とその測定記録はcommit `8b79c5c30b5447a511bebeb2d55164bda8362887`に残しています。
今回の高速化比較は、その弱い旧practiceではなく、既にあった強い固定方策rolloutを基準にしています。
