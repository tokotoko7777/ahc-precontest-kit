# AHC056 `Grid Turing Robot` 練習解

公式問題: [AHC056 A - Grid Turing Robot](https://atcoder.jp/contests/ahc056/tasks/ahc056_a)

`main.cpp` は、外部ライブラリを必要としない提出用C++17単一ファイルです。ランダム探索
を使わず、必ず全目的地を訪れる構成を出力します。

## 問題を短く言うと

ロボットは「現在マスの色 `c`」と「内部状態 `q`」だけを見て、次の3つを同時に行います。

- 現在マスを色 `A(c,q)` に塗る。
- 内部状態を `S(c,q)` に変える。
- `D(c,q)` の方向へ移動する。

指定された目的地を順番にすべて訪れた場合、絶対スコアは `C+Q` です。ここで `C` は
色数、`Q` は状態数で、スコアは小さいほど良くなります。

## 解法

### 1. まず、必ず成功する移動列を作る

連続する目的地をBFSの最短路で結びます。全てを連結した移動回数を `X` とすると、問題
の生成条件から `X <= T` です。したがって、この移動列を正確に再生できれば、制限手数
以内に全目的地を訪れられます。

### 2. 各時刻へ一意な `(色, 状態)` を割り当てる

`X` 個の時刻を、`C` 行 `Q` 列の表へ順番に置きます。

```text
color(t) = t / Q
state(t) = t % Q
```

`C*Q >= X` なら、異なる時刻が同じ `(color,state)` を持つことはありません。そのため、
時刻ごとに別の移動命令を置いても遷移規則が衝突しません。

`C+Q` が最小になるよう、`Q=1..X` を全部試し、

```text
C = ceil(X / Q)
```

として最良の組を選びます。結果はおおよそ `C ≈ Q ≈ sqrt(X)` なので、スコアは
おおよそ `2*sqrt(X)` です。

### 3. 次回訪問用の色をマスへ書いておく

同じマスを後でもう一度使う場合、そのマスを離れるときに「次回訪問時刻の色」へ
塗り替えます。各時刻を後ろから見ると、同じマスの次回訪問時刻を `O(X)` で求められます。

初期盤面には各マスの最初の訪問時刻の色を置きます。これで次の不変条件が成り立ちます。

> 移動列の時刻 `t` では、現在マスの色が必ず `color(t)` で、内部状態が必ず
> `state(t)` になっている。

よって、出力した規則はBFSで作った移動列を最後までそのまま再生します。

## 小さな例

移動が10回なら、`C=4, Q=3` とすれば12組の `(色,状態)` を使えます。

```text
t=0 -> (0,0)    t=1 -> (0,1)    t=2 -> (0,2)
t=3 -> (1,0)    t=4 -> (1,1)    t=5 -> (1,2)
t=6 -> (2,0)    t=7 -> (2,1)    t=8 -> (2,2)
t=9 -> (3,0)
```

各組は一度しか登場しないため、それぞれ好きな方向を安全に設定できます。

## コンパイルと実行

```bash
g++ -std=c++17 -O2 -DNDEBUG main.cpp -o main
./main < in.txt > out.txt
```

公式ローカルツールでは、次の形で実際の動作と絶対スコアを確認できます。

```bash
cargo run --release --bin vis in/0000.txt out.txt
```

## 以前の実験版を置き換えた理由

以前の焼きなまし版は、候補を却下した際にクラスタ集計だけを戻し、各時刻の所属情報を
戻していませんでした。そのため内部評価が0でも、出力した制御器が同じ経路を再生する
保証がありませんでした。実際に公式seed 0では `C+Q=4` を宣言したものの全目的地を
訪問できず、絶対スコア124875でした。

この版はスコア4のような極端な圧縮を狙う代わりに、短い証明で合法性を確認できる構成を
採用しています。seed 0の絶対スコアは64です。

## 計算量

- BFS: `O(K*N^2)`
- 移動列と次回訪問の処理: `O(X)`
- `C,Q` の選択: `O(X)`
- メモリ: `O(N^2+X)`

## この解から再利用できる部分

- 壁付きグリッドのBFSと経路復元。
- 後ろから走査して各要素の次回出現位置を求める方法。
- 長い実行列の各時刻を、2種類の記号の直積へ平方根分割する方法。
- ランダム探索の評価値ではなく、実際の実行不変条件で合法性を証明する考え方。

さらにスコアを下げるなら、同じ遷移を必要とする時刻同士を安全に併合する方法や、複数の
最短経路から圧縮しやすい経路を選ぶ方法が候補です。その場合も、内部の矛盾数だけでなく
最終出力を公式judgeで再生して確認する必要があります。
