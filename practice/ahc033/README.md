# AHC033 practice

公式問題: [A - Container Handling with Cranes](https://atcoder.jp/contests/ahc033/tasks/ahc033_a)

`main.cpp` だけで提出できる、5×5コンテナターミナルの練習例です。外部headerには依存しません。

## 問題の要点

- 左端5マスから、それぞれ5個のコンテナが決められた順で入ります。
- 番号 `5*r` から `5*r+4` は、右端の行 `r` から番号順に出す必要があります。
- 誤った行、番号の逆転、未搬出には、ターン数より非常に大きな罰点があります。
- 5台のクレーンは同じマスへ重なれず、位置交換もできません。
- 大型クレーンだけは、コンテナを持ったまま他のコンテナの上を通れます。

この例では、まず大きな罰点を完全に0にすることを優先します。

## 解法

### 1. 大型クレーン1台だけを使う

小型クレーン4台は最初のターンに `B` で撤去します。大型1台だけなら、クレーン同士の衝突・
位置交換・待ち合わせを考える必要がありません。さらに大型はコンテナを保持中でも盤面上の
箱を越えられるため、移動経路は単純なManhattan経路で十分です。

小型クレーンの最初の `B` と、大型クレーンの最初の行動は同時に実行されます。公式ルールでは
撤去されるクレーンのマスへ大型が移ることも可能です。

### 2. 各搬出口の「次の1個」だけを出す

行 `r` で次に必要な番号を管理します。その番号が入口または一時置き場に見えていれば、現在の
大型クレーン位置からの往復距離が短いものを選び、正しい行の右端へ運びます。

右端へ `Q` したコンテナは、そのターン末に自動で搬出されます。この選び方なら全ての行で
番号順が崩れません。

### 3. 必要な箱が見えなければ入口を空ける

次番号がまだ入口列の奥にある場合、その入口の先頭を内側3列、合計15マスの一時置き場へ
移します。5個の次番号のうち、入口からの深さが最小のものを優先して掘り進めるため、一時
置き場を使いすぎません。

一時置き場は、箱が最後に出る行へ近いマスを優先します。公式seed 0〜99では15マスが満杯に
なる場面はなく、全ケースで順序違反なしに25個を搬出できました。

念のため満杯時は、入口先頭を正しい行へ直送して処理を続けるfallbackもあります。これは
搬出自体の合法性を保ちますが、順序罰点が生じる可能性があります。

### 4. 公式の1ターンを小さなsimulationにする

`Terminal::step` が次をまとめて更新します。

1. 大型クレーンの `P/Q/U/D/L/R/.`
2. 右端からの自動搬出
3. 次ターン開始時の左端への自動搬入

盤面と出力文字列を同時に更新するため、「考えていた盤面」と「実際に出した操作列」のずれを
防げます。

## コードを読む順番

- `Terminal::step`: 1ターンの盤面更新
- `Terminal::carry`: 移動、取得、運搬、解放
- `choose_visible_target`: 今すぐ正しく搬出できる箱
- `choose_gate_to_clear`: 次に掘り進める入口
- `choose_storage`: 一時置き場の選択
- `solve_in_order`: 全25個を処理するmain loop

## コンパイル

通常版:

```bash
g++ -std=c++17 -O2 main.cpp -o solver
```

比較用の直送版は、一時保管せず入口先頭を正しい搬出口へそのまま運びます。

```bash
g++ -std=c++17 -O2 -DBASELINE_POLICY main.cpp -o baseline
```

直送版も誤った行への配送や未搬出はありませんが、同じ行の番号順が崩れるため逆転罰点が
発生します。

## 公式ローカルツールでの確認

[公式generator・visualizer](https://img.atcoder.jp/ahc033/ELSlXTEw.zip)のseed 0〜99で
確認しました。絶対スコアは小さいほど良い値です。

- 通常版は全100ケース合法、25個全て搬出
- 誤搬出・逆転・未搬出の罰点が全ケース0
- 通常版平均スコア: 338.13
- 通常版最小 / 最大: 305 / 370
- 直送baseline平均スコア: 2,848.96
- baseline平均ターン数: 287.96
- 通常版とbaselineの勝/分/敗: 100 / 0 / 0
- 平均スコアを約88.1%削減

通常版は罰点が0なので、全ケースでスコアと大型クレーンのターン数が一致します。seed 0は
347ターン・スコア347でした。

`-Wall -Wextra -Wshadow -pedantic` で通常版・baselineとも警告なしです。ASan・UBSanを
同時に有効にしたseed 0、37、99も完走し、公式visualizerでそれぞれ347、337、339でした。

## 計算量と発展

盤面は25マスしかなく、各判断で全マスを走査しても十分高速です。実装はおおよそ
`O(ターン数 × N^2)`、出力長は公式100ケースで最大370でした。

知識コーパスのAHC033 reviewでは、複数クレーンのタスク割当と時空間経路をビームサーチする
高度な方針が確認されています。ただし研究用代表の最終スコア対応は未確認です。この例では
その前段となる「合法性を構築時に保証する」「搬入口の詰まりを評価する」を採り入れ、初心者が
追える単一クレーン方針として独自実装しました。第三者の提出コードは使用していません。
