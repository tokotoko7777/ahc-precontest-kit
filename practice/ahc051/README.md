# AHC051 練習解答: Probabilistic Waste Sorting

提出するのは [`main.cpp`](./main.cpp) だけです。ローカルのヘッダやライブラリには依存していません。

## 問題を短く整理

`N` 種類のごみを、確率的な分別器を通して正しい処理装置へ送ります。

- 処理装置の設置場所は `N` 個あり、ごみ種類を重複なく1種類ずつ割り当てる
- 分別器は2本の出口を持ち、種類ごとに出口1へ進む確率が異なる
- 搬入口と使用する分別器の出口は、処理装置か使用中の分別器へ必ず接続する
- ベルト同士は、端点を共有しない限り交差禁止
- 搬送グラフは自己ループを含む閉路禁止

種類 `i` のごみが正しい処理装置へ着く確率を `q_i` とすると、絶対Scoreは次の値です。

```text
round(1e9 * average(1 - q_i))
```

この問題では、Scoreは小さいほど良くなります。

公式問題文: <https://atcoder.jp/contests/ahc051/tasks/ahc051_a>

## 基準解

処理装置 `i` にごみ種類 `i` を割り当て、搬入口を処理装置0へ直接つなぎます。分別器は1台も使いません。

この解は必ず合法です。種類0だけが確率1で正解し、ほかの種類は確率0になります。

## この解法

解法を「交差しない物理的な木」と「木の上での分類」の2段階に分けています。

### 1. 交差しない二分木を作る

最初は、搬入口から処理装置1台へ辺を1本引きます。その後、既存の処理装置の葉へ入る辺を、次のY字形へ置き換えます。

```text
変更前: 親 -> 古い処理装置

変更後: 親 -> 新しい分別器
                  |-> 古い処理装置
                  `-> 新しい処理装置
```

この変更では葉を1個ずつ増やせます。浅い葉から優先的に分割するので、木はほぼ平衡になります。

候補を追加する前に、公式判定器と同じ整数の外積で全ベルトとの交差を調べます。既存の葉辺を置き換えるだけなので閉路は生まれません。最終的に `N` 個の処理装置と `N-1` 個の分別器からなる平面二分木になります。

万一、最後まで木を作れなかった場合は、必ず合法な基準解へ戻ります。

### 2. ごみ種類と分別器を決める

処理装置の種類は自由に並べ替えられ、同じ分別器種類は何度でも使えます。そのため、物理的な木を変えなくても分類方法を改善できます。

まず根から再帰的に、各部分木の葉数に合わせてごみ種類を左右へ分けます。それぞれの分別器について対数確率を計算し、左側へ送るべき種類と右側へ送るべき種類が最も分かれやすい分別器と出口向きを選びます。

次に、公式式と同じように根から葉までの確率を掛け、`sum(q_i)` を正確に評価します。以下を交互に繰り返して改善します。

- 1個の分別器の種類と出口向きを全候補から選び直す
- 2台の処理装置に割り当てたごみ種類を交換する
- 現在の最良解へ数回の交換を加え、再び局所改善する

探索は1.6秒で終了します。乱数の初期値は固定してあり、実行を再現しやすくしています。

## 主な関数

- `build_geometry`: 平面二分木を作る
- `insertion_is_planar`: 新しい3辺が既存辺と交差しないか確認
- `greedy_logical_assignment`: 対数確率で初期分類を作る
- `evaluate`: 各種類の正解到達確率を厳密に計算
- `improve_sorters`: 分別器種類と出口向きの局所改善
- `improve_one_type_swap`: 処理装置の種類割当を交換

独自namespaceや外部ライブラリは使わず、1ファイル内の小さな関数へ処理を分けています。
