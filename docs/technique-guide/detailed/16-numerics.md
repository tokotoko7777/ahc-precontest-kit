## D295. 対数確率の正規化

非常に小さい確率をそのまま掛けると0へ丸められます。対数で保持し、正規化するとき最大値を引いてから指数へ戻します。

対数値が−1000と−1001なら、0と−1へずらします。両方へ同じ倍率を掛けても正規化後の比率は変わりません。

<a id="example-23016921-03"></a>
### コードでの具体例：最大対数尤度を引いてからexpする

有効モデルの最大対数尤度を全モデルから引き、exp後に総和で割る。

**適用条件・落とし穴。** 長い逐次観測で確率のunderflowを抑える基本部品。

**検算と練習。** 全尤度が非常に小さい場合とモデルが一つだけのケースを試す。

## D296. 定常分布の計算

遷移を繰り返しても変わらない分布は、分布πに対してPの転置を掛けてもπになる条件で表せます。

これだけでは全体の倍率が決まらないので、確率の合計1という式を加えます。分布が一意でない連鎖や、数値的に不安定な行列も別に検査します。

<a id="example-65957786-01"></a>
### コードでの具体例：定常方程式の一行を確率総和1に置き換える

Pの転置から単位行列を引き、一行を正規化条件にして部分ピボット付き消去法で解く。

**適用条件・落とし穴。** 小状態数の連鎖向け。可約・特異な場合に対角を飛ばす処理だけでは一意で安定な解を保証しない。

**検算と練習。** 既知の定常分布と比較し、残差と非負性も検査する。

## D297. 凸結合の係数

混合の重みの和が1なら、最後の重みを他の重みから決められます。

4色の重みをa,b,c,1−a−b−cと置けば、未知数は3個です。方程式の解が出ても、負の重みを含めば実際の混合では使えないため、非負条件を確認します。

<a id="example-66623158-01"></a>
### コードでの具体例：4色の配合を3変数の連立方程式へ落とす

4番目の色との差分を列にした3×3系を解き、最後の重みを1から他の和を引いて復元する。

**適用条件・落とし穴。** 3次元色空間のアフィン結合。小ピボットをepsに置き換えるだけでは退化四面体の精度を保証しない。

**検算と練習。** 同一色・ほぼ共面の4色で残差と非負重みを確認する。

出典: [AHC048 / 提出 66623158](https://atcoder.jp/contests/ahc048/submissions/66623158) · `SolveWeights / makePlan` · L754–L781, L1454–L1534。 [収録情報](SOURCES.md#submission-66623158)

## D298. 連続解の離散化

理想の連続値を、実際に実行できる整数比へ近づけます。

希望割合0.37、分母8なら、3/8=0.375が候補です。割合の近さだけでなく、操作可能な容積や区画サイズ、余る量も比較に含めます。

<a id="example-66623158-04"></a>
### コードでの具体例：希望配合量を分母制限付きの分数に近似する

区画サイズを分母として上下丸めの分子を試し、必要なら一部を隔離して残部の分数を再探索する。

**適用条件・落とし穴。** 容量分割で実現する連続量の丸め。分母0・空在庫・必要量ゼロを別扱いにする。

**検算と練習。** 実操作シミュレータの量と分数で見積もった量を比較する。

出典: [AHC048 / 提出 66623158](https://atcoder.jp/contests/ahc048/submissions/66623158) · `getNearestRecipeForWill / getNearestFraction` · L1880–L1973。 [収録情報](SOURCES.md#submission-66623158)

## D299. 多段生産の閉形式

同じ更新を何回も繰り返す処理は、累積の累積として式にまとめられる場合があります。

毎回1ずつ増える生産量の合計には三角数が現れ、さらに段を重ねると高次の二項係数が現れます。更新順で添字が変わるため、小さい回数の逐次実行と照合します。

<a id="example-71725942-01"></a>
### コードでの具体例：連続待機を二項係数の式でまとめて進める

上位から下位へ増える生産系列のk回更新を、k・組合せkC2〜kC4を使う式に置き換える。

**適用条件・落とし穴。** 三角形の依存関係を持つ線形漸化式向け。各段の更新順が係数を決める。

**検算と練習。** 逐次更新とk=0,1,2や最大待機長で整数一致を確認する。

出典: [AHC058 / 提出 71725942](https://atcoder.jp/contests/ahc058/submissions/71725942) · `fast_forward_noop / c2 / c3 / c4` · L129–L204, L480–L484。 [収録情報](SOURCES.md#submission-71725942)

## D300. 巨大整数の対数評価

巨大な資源量は整数で正確に持ち、比較の尺度だけ対数へ変えると、倍率に対する改善を扱いやすくなります。

10から20と100から200は、対数差では同じ倍増です。対数は正の値の大小順を保ちますが、差分で受理確率を決める探索の挙動は変わります。

<a id="example-71725942-05"></a>
### コードでの具体例：整数状態を保ち、SAの評価だけ対数へ変換する

資源量は128bitで保持し、上位53bit程度を使ってlog2を計算する。SA差分を絶対量から倍率に近い尺度へ変える。

**適用条件・落とし穴。** 桁が大きく増える目的向け。内部b配列は64bitなので別に上界確認が要る。

**検算と練習。** 境界値の対数誤差と全中間積の最大値を調べる。

出典: [AHC058 / 提出 71725942](https://atcoder.jp/contests/ahc058/submissions/71725942) · `u128 / log2_u128` · L53–L59, L72–L94, L745–L750。 [収録情報](SOURCES.md#submission-71725942)
