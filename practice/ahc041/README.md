# AHC041 - 重み付き深さ制限DFSと部分木の付け替え

## 問題をどう見るか

頂点 `v` を深さ `d` に置くと、得点への寄与は

```text
(d + 1) * A[v]
```

です。したがって、価値 `A[v]` が大きい頂点ほど深さ10へ置き、木を支えるために必要な浅い頂点には価値が小さいものを使いたい問題です。

出力するのは各頂点の親だけです。親が元グラフの隣接頂点であり、親をたどった深さが10以下なら合法です。座標はグラフ生成と表示には使われますが、得点計算には直接使われないため、この solver では読み飛ばします。

## 初期解: 深さ制限付きDFS

未使用頂点から根を一つ選び、DFSで木を伸ばします。ただし、深さ10へ到達したら、それより先へは進みません。まだ未使用の頂点が残った場合は、新しい根から次の木を作ります。

頂点を選ぶ順番が重要です。

- 深さ0～9: `A` が小さく次数が大きい頂点を優先する。浅い場所で多くの子を支えてもらう。
- 深さ10: `A` が大きい頂点を優先する。ここはもう子を持てないため、得点を優先する。
- 新しい根: `A` が小さく次数が大きい頂点を優先する。

順位へ小さな乱数を加えたDFSを多数作り、公式得点が最大のものを残します。次数の重みは通常範囲と強めの範囲を両方試します。乱数seedは固定なので、同じ入力には毎回同じ答えが出ます。

## 後処理: 部分木を丸ごと深くする

初期解の上位6個には、親の付け替えを行います。

頂点 `v` の部分木に含まれる価値の合計を `subtree_sum[v]` とします。この部分木を今より `delta` 段深くできるなら、得点増分は

```text
delta * subtree_sum[v]
```

です。

全ての元グラフの辺を調べ、増分が最大の付け替えを繰り返します。次の二つは必ず確認します。

1. 新しい親が `v` の部分木内ではないこと。これで閉路を防ぐ。
2. 移動後の部分木の最深部が深さ10以下であること。

部分木の区間はDFSの行きがけ・帰りがけ時刻で判定し、部分木の高さと価値合計も同じDFSで計算します。

## 合法になる理由

- 初期DFSでは、未使用頂点だけを現在頂点の子にするため閉路ができません。
- 使用する親子辺は必ず入力グラフの辺です。
- 深さ10では探索を止めます。
- 付け替えでは部分木内への接続を禁止し、移動後の最大深さも確認します。
- 全頂点をいずれかの根付き木へ一度だけ入れます。

## 使い方

```bash
g++ -std=c++20 -O2 -pipe -Wall -Wextra -Wshadow main.cpp -o main
./main < input.txt > output.txt
```

提出には `main.cpp` だけを使います。ローカルヘッダや外部ファイルには依存しません。

比較用の単純基準解も同じファイルから作れます。

```bash
# 頂点0からBFS木を作り、11層ごとに親辺を切る
g++ -std=c++20 -O2 -DAHC041_BASELINE main.cpp -o main-baseline

# DFS試行を40回に減らす100ケース確認用
g++ -std=c++20 -O2 -DLOCAL_SHORT_TIME main.cpp -o main-short
```

## 計算量

1回の初期解構築は、各頂点と辺をほぼ一度ずつ見て、小さい隣接リストを整列する計算です。通常版は15,000通り、軽量版は40通りを試します。

部分木付け替えの1反復では、木情報の再計算が `O(N)`、候補辺の確認が `O(M)` です。`N=1000, M<=3000` なので、単純に全候補を調べても十分間に合います。
