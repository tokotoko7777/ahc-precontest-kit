# AHC062 practice

公式問題: [A - AtCoder Kingdom Tour](https://atcoder.jp/contests/ahc062/tasks/ahc062_a)

`main.cpp` だけで提出できる、C++17の過去問練習です。ローカルヘッダは参照せず、
必要な部品をファイル上部へ直接置いています。

## 問題を短く言うと

- `N = 200` の盤面に、人口 `1` から `N^2` がランダムに並ぶ
- 全 `40000` マスをちょうど一度ずつ訪問する
- 次のマスへは縦・横・斜めの8近傍で移動する
- `k` 日目の人口に `k` が掛かるので、大きい人口を後ろへ置きたい

目的値を `V = sum(k * A[path[k]])` とすると、公式スコアは
`round(V / N^2)` です。

## 解法

### 1. 最初から絶対に合法な閉路を作る

盤面を4列ずつ組み合わせ、全マスを一度ずつ通るHamilton閉路を作ります。
巨大な座標列は埋め込まず、`make_four_column_cycle()` の短いループで生成します。

閉路なので、最後のマスと最初のマスも隣接しています。開始位置をどこへ動かしても
合法な訪問順になるのが利点です。

### 2. テンプレート内の二択を人口で決める

この4列テンプレートには、隣接する2マスのどちらを先に通るかを独立に選べる場所が
多数あります。2マスの人口を見て、人口が大きい方が後ろになる場合だけ入れ替えます。

これは任意の経路で使えるswapではありません。対象となる二択を全部決め終えた状態が
合法になるよう、閉路テンプレートと組にした問題専用の複合近傍です。

盤面を0度・90度・180度・270度回した4通りと、巡回方向2通りの合計8候補を作ります。
二択の決定と次節の「閉路を切る位置」を3回交互に改善し、目的値が最大の候補を選びます。

### 3. 閉路を切る一番良い場所を全探索する

閉路の並びを1マスずらすと、先頭要素だけが末尾へ移ります。現在値を `F`、人口の
総和を `S`、今の先頭人口を `a` とすると、次の開始位置の値は

```text
F_next = F + N^2 * a - S
```

です。この式により、全 `40000` 通りの開始位置を `O(N^2)` で比較できます。

### 4. 2-optで経路を改善する

2本の辺 `(a,b)`, `(c,d)` を選び、`a-c` と `b-d` がどちらも8近傍なら、
`b` から `c` までを反転できます。区間内部の辺は向きが逆になるだけなので、
調べる必要があるのは新しい境界2辺だけです。

区間 `[l,r]` を反転したときの目的値変化は、人口のprefix sumを使って

```text
delta = (l + r) * sum(A[k]) - 2 * sum(k * A[k])
```

と `O(1)` で求めます。改善する手だけを採用する山登り法です。候補の2本目は
`a` の8近傍だけから探すため、全位置の組を調べません。

最後に、前後の辺がすべて合法だと局所確認できるセル交換で小さな改善を拾います。
交換候補も各マスの8近傍だけを順に全確認し、改善がなくなるまで繰り返します。
2-optとセル交換は、一方の改善でもう一方の候補が再び生まれるため、両方が止まるまで
交互に実行します。

## 使用したパーツ

- `Timer` — `library/timer.hpp` と同じ単純な経過時間計測を貼り付け
- `NeighborTable` — 各マスの8近傍を固定長配列へ前計算
- prefix sumによる区間反転delta
- 位置逆引き `position[cell]`

prefix sumは経路を反転するたびに作り直す必要があります。更新後も古いprefixを使う
誤用が起きやすいため、この短い問題専用処理は独立ヘッダにせず、共通ファイルも
増やしていません。
