# AHC006 practice

公式問題: [A - Food Delivery](https://atcoder.jp/contests/ahc006/tasks/ahc006_a)

`main.cpp` だけで提出できる、過去AHCを使ったライブラリ実戦例です。

## 使用したパーツ

- `BatchedTimer`
- `Random`
- `SimulatedAnnealing`
- `BestKeeper`
- `RouteUtils`

パーツはローカルヘッダとして参照せず、`main.cpp` の上部へ直接貼っています。

## 独自解法

単独で往復した時の距離が短い50注文を選び、pickupをdeliveryより前に置く制約を
守りながら、各注文を経路の最良2位置へ挿入して初期解を作ります。

その後、次の4近傍を焼きなまします。

- pickupまたはdeliveryを、先行制約を守れる位置へ移動
- 2イベントのswap
- 区間reverse
- 選択中1注文と未選択1注文の交換＋最良位置への再挿入

各候補は採用前にpickupがdeliveryより先か検査します。探索中の解とは別に
`BestKeeper` で最良解を保存します。

## この練習で追加した汎用パーツ

`route-utils.hpp` を追加しました。点の型や距離関数を固定せず、経路長と挿入・削除・
区間反転の距離差分を計算できます。

## 公式ツールでの確認

公式配布のseed 0〜9で、全ケースが正しい形式・制約を満たしました。

- 平均スコア: 19271.50
- 最小スコア: 18096
- 最大スコア: 20627

実行時間で反復回数が変わるため、同じ入力でもスコアは多少変動します。
