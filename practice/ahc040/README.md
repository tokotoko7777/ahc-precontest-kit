# AHC040 練習用ソルバー

[AHC040 A - Packing Uncertain Rectangles](https://atcoder.jp/contests/ahc040/tasks/ahc040_a)
の、提出可能な単一 `main.cpp` です。ローカルheaderには依存しません。

## 問題の見方

各長方形の幅と高さは最初から観測できますが、標準偏差 `sigma` の誤差を含みます。配置を
1回送るたびに、その配置の外接幅と高さも同じ誤差付きで返ります。全turn中で実際の
`幅+高さ` が最小だった配置だけが絶対得点になるため、次の2つを両立できます。

- 前半の少数turnで寸法を測り直す
- 後半は縦横比の異なる完成配置を何案も提出する

## 解法

### 1. 横一列・縦一列を線形測定にする

横一列へ置くと、外接幅は「各長方形で選んだ向きの幅」の総和です。縦一列なら外接高さが
総和になります。回転patternを毎回変えて最大20本の総和を観測します。

未知量を `w_0,h_0,w_1,h_1,...` のベクトルと考えると、これは係数0/1の線形式です。最初の
各寸法を平均、分散を `sigma^2` とする正規分布から始め、観測のたびにKalman更新します。
共分散行列全体を持つため、「前回の総和観測で生じた寸法間の相関」も次の更新へ残ります。

測定回数は次で制限し、turnの4分の3以上を完成配置へ残します。

```cpp
min(20, N / 4, T / 4)
```

### 2. bottom-left配置を作る

長方形は番号順に置く必要があります。長方形 `i` を追加する時、次をすべて比較します。

- 回転する・しない
- 上へ詰める `U`、左へ詰める `L`
- 基準長方形 `b=-1,0,...,i-1`

候補を実際にシミュレーションし、目標幅を超えにくく、高さと空き面積が小さい置き方を
greedyに選びます。物理的な `U` / `L` 操作そのものを再現するので、推定寸法が真値と
ずれていても出力の合法性は壊れません。

### 3. 目標幅を広く探索してから絞る

総推定面積の平方根を正方形の一辺の目安にします。後半の最初の最大24turnでは、目標幅を
その `0.62` 倍から `1.54` 倍まで均等に試します。その後は観測された `W'+H'` が最良だった
幅の近くを乱択し、空き面積の重みや小さな候補揺らぎも変えます。

返る値にはノイズがありますが、最良候補だけへ固定せず探索を続けます。評価対象は全turnの
真の最小値なので、途中で良かった配置も失われません。

## まず使う

この問題は対話型なので、ローカルでは公式testerを間に入れます。

```bash
g++ -std=c++20 -O2 -pipe main.cpp -o solver
./target/release/tester /path/to/solver < in/0000.txt > out.txt
./target/release/vis in/0000.txt out.txt
```

`-DAHC040_BASELINE` を付けると、短い辺を横向きにして全長方形を一列へ並べる比較用解に
なります。

```bash
g++ -std=c++20 -O2 -DAHC040_BASELINE main.cpp -o baseline
```

測定の効果だけを外す場合は `-DAHC040_MEASUREMENT_LIMIT=0` です。既定の最大測定回数20も
同じmacroで変更できます。

## 計算量

完成配置1案は、各長方形について過去の全基準位置を試し、衝突判定でも過去長方形を見る
ため `O(N^3)` です。寸法更新は未知量が `2N` 個なので、1観測あたり `O(N^2)` です。
`N<=100` では十分小さく、動的確保も探索の外側へ寄せています。

公式seed 0〜99では次の結果でした。

- 全100ケースで対話完走、公式visualizerでも合法
- 平均: `3,502,197.20 -> 1,204,802.06`
- baselineとの勝/分/敗: `100/0/0`
- 100ケース合計の削減率: `65.60%`
- 最終版の範囲: `705,624`〜`1,779,458`
- 面積だけから得る理論下界 `2*sqrt(総面積)` に対するseed別倍率の平均: `1.1800`
- seed 99のsolver+tester: `0.01秒`、約 `2.1 MiB`

完全共分散の測定あり版と測定なし版も同じ100seedで比較しました。

- 測定なし平均: `1,205,307.09`
- 測定あり平均: `1,204,802.06`
- 勝/分/敗: `50/6/44`

差は小さいものの、合計では測定あり版が `0.0419%` 良くなりました。測定を対角分散だけで
更新する版は30seedで悪化したため採用せず、相関を残す現在の更新へ置き換えています。

通常版・baseline版は
`-Wall -Wextra -Wshadow -Wconversion -Werror` を通過しました。ASan+UBSanはseed 0, 37,
99で対話完走後、各出力を公式visualizerへ再入力しています。
