# 03. 近傍・破壊再構築

[詳細編の目次](README.md) · [用語](GLOSSARY.md) · [出典一覧](SOURCES.md)

近傍は『1回の試行で何を変えるか』の設計です。小さい変更は安く、多要素の変更は行き詰まりを越える可能性を持ちます。何を壊し、何を固定し、どの条件で修復できたと判断するかを読み比べてください。

説明用の小例と、提出コードで確認した具体例を分けて記載しています。適用効果は未測定で、検算と練習はこれから確かめるための課題です。

## D064. 局所破壊再構築

一部の決定を取り消して作り直すと、1要素ずつでは抜けられない配置の行き詰まりを動かせます。

例えば隣接する3区画をいったん小さくし、空いた場所を配り直します。壊す範囲が大きいほど自由になりますが、修復の費用と失敗率も増えます。

<a id="example-20926292-05"></a>
### コードでの具体例：不満足領域の周囲9個だけを点へ縮める

損失のある領域を中心に近傍9領域を最小サイズへ縮め、その集合を再配置する。

**適用条件・落とし穴。** 破壊の中心を改善余地のある部分へ偏らせるLNS。

**検算と練習。** 破壊後も点包含・非重複が保たれるか確認し、破壊範囲別に比較する。

## D065. 区間修復の向き反転

端点が同じでも、先にどちらから伸ばすかで貪欲な修復結果は変わります。

左側は道が1本、右側は3本あるなら、開始側によって早く使い切る自由度が違います。逆向きに作った列は、元の経路へつなぐ向きに戻して使います。

<a id="example-22075413-04"></a>
### コードでの具体例：接続方向を半々に切り替える

左端から右端と右端から左端のDFSを選び、逆向き探索の結果は逆順に復元する。

**適用条件・落とし穴。** 探索順序の非対称性を多様性として使う。

**検算と練習。** 両方向で端点の二重計上・除去区間の境界ずれを確認する。

## D066. 時間に応じた破壊幅

序盤は大きく配置を変え、終盤は短い範囲を磨く設計です。温度だけでなく、候補自体の大きさも時間で変えます。

経路の20点を作り直す試行から、最後は3点の修復へ移る、と考えると分かりやすいでしょう。幅を縮めすぎると必要な変更まで消えます。

<a id="example-22075413-05"></a>
### コードでの具体例：終盤ほど短い区間を修復する

残時間比から温度と区間幅を同時に小さくする。

**適用条件・落とし穴。** 序盤の大変更と終盤の細かい改善を両立する。係数は問題ごとに測る。

**検算と練習。** 残時間0と長さの短い経路で乱数範囲が正になるか確認する。

出典: [AHC002 / 提出 22075413](https://atcoder.jp/contests/ahc002/submissions/22075413) · `SA` · L330–L350。 [収録情報](SOURCES.md#submission-22075413)

## D067. ランダム候補と構造候補の混合

有望そうな相手を選ぶ候補と、広い範囲を探索する候補を混ぜます。構造だけで選ぶと見落とす場所へも移れるようにします。

文字列の重なりが大きい相手の隣を多く試し、ときどき全体から挿入位置を選ぶ、といった構成です。

<a id="example-23751222-03"></a>
### コードでの具体例：移設先を乱択と重なり相手から選ぶ

通常のランダム挿入に、前後の大きな重なりを持つ要素の隣へ挿す提案を混ぜる。

**適用条件・落とし穴。** 局所に偏る候補制限へ無制限の探索も残す。

**検算と練習。** 候補リストが空の場合の処理と、混合比による品質・試行数を確認する。

## D068. 代表点と順序の同時最適化

どのグループを訪れるかが固定でも、代表位置と訪問順は一緒に選び直せます。

通路Aを訪れる代表点を左端から交差点へ替えると、前後の通路との接続が短くなるかもしれません。代表点だけを先に固定すると、この改善を逃します。

<a id="example-24829216-03"></a>
### コードでの具体例：一つの通路を抜き最良の交点・挿入位置へ戻す

代表群は固定したまま、群内の全交点と全挿入位置の増分費用を比較する。

**適用条件・落とし穴。** 選択肢付き巡回の単なる2-optより大きな変更を作れる。

**検算と練習。** 元の位置も候補に残ること、差分と全経路費用の一致を確認する。

出典: [AHC005 / 提出 24829216](https://atcoder.jp/contests/ahc005/submissions/24829216) · `NA` · L72–L106。 [収録情報](SOURCES.md#submission-24829216)

## D069. 複数要素の貪欲修復

複数要素を抜いてから戻すと、お互いが占めていた場所を交換できます。

経路からAとBを外し、Aの最良位置、次にBの最良位置を探します。戻す順番でも答えが変わるので、同じ破壊集合でも複数の修復を作れます。

<a id="example-24829216-04"></a>
### コードでの具体例：ランダム個数を除去して順に再挿入する

複数の通路代表を取り除き、各々を群内代表も選び直しながら最安位置へ入れる。

**適用条件・落とし穴。** 単要素改善が止まった順序問題への破壊再構築。

**検算と練習。** 除去群が重複せず、修復後も各群が一つずつ現れるか確認する。

出典: [AHC005 / 提出 24829216](https://atcoder.jp/contests/ahc005/submissions/24829216) · `DA` · L111–L147。 [収録情報](SOURCES.md#submission-24829216)

## D070. 先行制約を守る反転

区間を反転すると、その中に両方入ったペアの順序が逆になります。区間内外に分かれたペアの先後関係は変わりません。

「集荷→配送」を守るなら、両方を含む区間の反転を禁止できます。局所操作がどの制約だけ壊すかを特定する例です。

<a id="example-27260278-02"></a>
### コードでの具体例：区間内に同じ注文が二回あれば反転を拒否する

区間反転で順序が逆転するのは両端とも区間内にいるペアなので、注文IDの重複を調べる。

**適用条件・落とし穴。** ペアの前後関係だけを守る反転判定を簡潔にできる。

**検算と練習。** 両端入り・片端だけ・区間外の三ケースを試す。

出典: [AHC006 / 提出 27260278](https://atcoder.jp/contests/ahc006/submissions/27260278) · `canReverse` · L315–L322, L492–L503。 [収録情報](SOURCES.md#submission-27260278)

## D071. 可変長コマンド列

命令列の内容だけでなく長さも変えると、余分な命令の削除と必要な命令の追加を探索できます。

長さが上限100なら追加は試せませんが、置換や移設はできます。無効な種類を選び続けて、試行の大半を捨てないようにします。

<a id="example-30423648-05"></a>
### コードでの具体例：重複・追加・削除・方向変更・移設を分ける

長さ上限や下限に応じて無効な操作をスキップし、5種類の列操作を選ぶ。

**適用条件・落とし穴。** 頑健性のための反復と経路そのものの変更を別近傍にする。

**検算と練習。** 各近傍の長さ・方向・添字制約と有効率を測る。

出典: [AHC009 / 提出 30423648](https://atcoder.jp/contests/ahc009/submissions/30423648) · `annealing neighborhood match` · L279–L347。 [収録情報](SOURCES.md#submission-30423648)

## D072. 閉路の部分再接続

区間をつなぎ直すとき、位置だけ一致しても接続できるとは限りません。端点で必要な向きも修復条件に入れます。

同じセルへ到達しても、出口が東向きなら北向きの既存経路へはつながりません。接続境界の情報を修復問題へ渡します。

<a id="example-31233938-02"></a>
### コードでの具体例：区間を解放し端点の方向まで指定して修復する

旧区間の使用数を外し、開始・終了の座標と方向を一致させるDFSで代替区間を探す。

**適用条件・落とし穴。** 連結構造を保ったまま経路を大きく変更する。

**検算と練習。** 修復失敗後に使用数・盤面・閉路判定が元へ戻るか確かめる。

出典: [AHC010 / 提出 31233938](https://atcoder.jp/contests/ahc010/submissions/31233938) · `solve::dfs` · L383–L431, L505–L524。 [収録情報](SOURCES.md#submission-31233938)

## D073. 木を保つ辺交換

木へ辺を1本加えると、閉路がちょうど1つできます。その閉路から別の辺を1本外せば、連結な木を保てます。

A–B–Cの木へA–Cを足し、B–Cを外すと、別の木へ移れます。任意の辺を削ると分断するので、削除候補を閉路上に限ります。

<a id="example-32267675-01"></a>
### コードでの具体例：非木辺を加えた閉路上から一本外す

連結な木を作り、追加辺の両端を結ぶ既存パスから除去辺を選んで木構造を維持する。

**適用条件・落とし穴。** 連結性制約を近傍の構造で守る。

**検算と練習。** 各交換後の辺数と連結性を全検査する。

出典: [AHC011 / 提出 32267675](https://atcoder.jp/contests/ahc011/submissions/32267675) · `BuildRandomGraph / FullSA` · L617–L633, L682–L741。 [収録情報](SOURCES.md#submission-32267675)

## D074. 小移動と大移動の混合

小さな移動は既存の順序を保った更新、大きな移動は列からの削除・再挿入として扱います。

切断座標5を6へ動かす場合と、隣の座標8を越えて10へ動かす場合を分けます。後者で位置だけ変えると、ソート済みという前提が壊れます。

<a id="example-32961594-06"></a>
### コードでの具体例：隣接線を越えた移動は削除と再挿入へ切り替える

近い座標への移動と広域の座標提案を混ぜ、順序を越えればlower_boundで挿入位置を求める。

**適用条件・落とし穴。** 連続位置の局所調整と大変更を同じソート列で扱う。

**検算と練習。** 同じ座標に重なる場合と複数線をまたぐ場合の復元を確認する。

## D075. 構築順序の変更

完成状態の座標を変えるだけでなく、それを作る優先順や開始点を変える近傍も作れます。

赤→青の順を青→赤へ変えると、同じ貪欲構築でも空間の取り合いが変わります。変更後の構築器まで含めて評価する必要があります。

**適用条件・落とし穴。** 貪欲構築の順序依存が大きい問題。位置が同じでも出力が変わる変数を状態に残す。

**検算と練習。** 各近傍を外した比較と、近傍別の受理率を測る。

## D076. 依存先を含む破壊

ある要素を消すと、それを材料にして作られた後続要素も成立しなくなることがあります。

点Pから矩形Aを作り、Aの新しい点からBを作ったなら、Aだけの削除では足りません。依存の連鎖を消去集合へ広げ、修復可能な大きさに抑えます。

<a id="example-35264600-02"></a>
### コードでの具体例：消す矩形の描画点を使う後続矩形も連鎖削除する

矩形列を前向きに走査し、削除済み点を参照する矩形を削除集合へ追加する。連鎖が上限を超えたら起点を引き直す。

**適用条件・落とし穴。** 生成物が後の操作の前提になる構築列。単一要素削除では合法性を保てない。

**検算と練習。** 削除後に全操作を順に再生して各頂点の存在を検査する。

出典: [AHC014 / 提出 35264600](https://atcoder.jp/contests/ahc014/submissions/35264600) · `DeleteRectRandomInt` · L3921–L3962。 [収録情報](SOURCES.md#submission-35264600)

## D077. 局所領域の再割当

同じ場所へ集まる要素をまとめて割り当て直すと、局所的な競合を一度に解きほぐせます。

交差点に接する道路4本の日程を全部外してから決め直すと、1本交換では難しい日程の循環変更も作れます。

<a id="example-38643777-03"></a>
### コードでの具体例：1頂点の周辺道路をまとめて外して日程を再構築する

選んだ頂点の全隣接辺を解除し、辺順をシャッフルして各辺の工事日を貪欲に決め直す。単純な2辺交換ではない。

**適用条件・落とし穴。** 近接道路の同時閉鎖に相互作用がある日程問題。各日の容量上限を維持する。

**検算と練習。** 1辺移動だけの版と、周辺まとめ直しを加えた版を比較する。

## D078. 他の部品からの移管

新しい部品を空き領域だけから作るのではなく、既存部品から一部を移管します。

Aの端のセルをBへ渡しても、Aの連結性と必要な被覆が残るなら候補になります。受け取る側だけでなく、渡す側の条件も検査します。

<a id="example-40290839-05"></a>
### コードでの具体例：被覆と連結を壊さないセル対を他ブロックから奪う

片側だけ占有済みの候補について、元ブロックの投影被覆を減らさず分断もしない場合にセル対を移管する。新ブロックの冗長な葉も除く。

**適用条件・落とし穴。** 部品境界にとらわれない構築が必要な場合。合同な対と両側の制約を一緒に更新する。

**検算と練習。** 移管前後の全投影、各ブロックの合同性・連結性を検算する。

出典: [AHC019 / 提出 40290839](https://atcoder.jp/contests/ahc019/submissions/40290839) · `GrowNext` · L834–L882。 [収録情報](SOURCES.md#submission-40290839)
