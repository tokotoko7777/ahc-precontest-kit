# AHC004 practice

[公式問題](https://atcoder.jp/contests/ahc004/tasks/ahc004_a)の過去問練習です。
`main.cpp`だけで提出でき、外部ヘッダは不要です。AtCoderへの提出はしていません。

## フォーマットと編集箇所

[保守用の例](../../examples/search/ahc004_genome_sa.cpp)は、
[局所探索の基本フォーマット](../../template/search/local-search/basic.cpp)と同じ
`TimeBasedAnnealingRunner`を使います。practiceにはヘッダを展開してあります。
時計・冷却・採否・最良解の保存はライブラリへ任せ、次の部分だけを問題ごとに書きます。

| 箇所 | 何を書くか |
|---|---|
| `State` | 盤面、語の出現回数、行・列の一致一覧、評価用cache |
| `Move` | 変更するセル番号と変更後の文字 |
| `propose_move` | 未収録語の上書き候補を1個返す。作れなければ`nullopt` |
| `evaluate_move` | **新評価−旧評価**を返す。Stateは変更しない |
| `apply_move` | 採用された手だけを、評価時に計算したcacheとともに反映 |

各箇所に日本語のTODOコメントを置いています。`evaluate_move`の第3引数は
途中打ち切り用の受理閾値です。この例では安全な上限枝刈りは未実装のため、
閾値を無視して正確な差分を最後まで計算します。

## 解法

20×20の盤面に、入力語を右向きまたは下向きの巡回部分列として埋め込みます。
全語未達なら被覆語数、全語達成時だけ空白数が公式得点に寄与します。
重複入力は頻度を重みにして数えます。制限時間は3秒です。

1. 長い語と重なりを優先した多点貪欲で初期盤面を作る。
2. 未収録語を選び、既存文字との一致が多い位置へ上書きする焼きなまし。
3. 変更した行・列だけを`AhoCorasick<8>`で走査して出現数を更新する。
4. 採用時だけStateを変更し、終了時はRunnerが保持する最良盤面を出力する。

初期構築150ms、探索終了の目安2780ms、温度6→0.03です。
1行を3bit/文字の整数にし、空白は別のbit列に保持します。
XORとpopcountで全800配置の一致度を調べ、同点は均等抽選します。
この一致度は近傍生成用の代理値で、受理判定には必ず正確な被覆数を使います。

巡回端は「20文字＋最大語長−1文字」を読んで処理します。
開始位置が20未満の一致だけを数え、同じ語の複数出現を保持します。
評価中のscratchはProblem側に置くので、不採用手のrollbackも、
最良解保存時のscratchコピーも必要ありません。

## 汎用部品

- [時間制限付き焼きなましRunner](../../library/time-based-simulated-annealing.hpp)
- [Aho-Corasick](../../library/aho-corasick.hpp)：今回追加した複数パターン照合。
  文字を整数へ変換して登録し、`build()`後は1文字ずつ状態を進めて一致IDを取得。
  入力アルファベット数はテンプレート引数で指定できます。
- 初期構築には従来のTimer、Random、suffix-prefix重なり計算を引き続き使用。

## 評価と再現

[5回の改善比較・未使用20ケースの確認](../../benchmarks/AHC004_FIVE_ROUNDS_REPORT.md)、
[生データ](../../benchmarks/results/)、[固定ソースと実験条件](../../benchmarks/ahc004_five_rounds/)
を保存しています。不採用案も残します。

公式visualizerと独立した巡回文字列採点を全出力で照合し、
3秒超過・不正出力は比較時に0点扱いです。反復数ではなく、入力ごとの
共通最高点を分母にした実問題の相対スコアを主指標にしています。

差分更新は全文字比較と照合します。空白、重複、包含語、巡回端、
採用・棄却後のcache、全語達成時の空白bonusをテストします。

## 限界

元盤面の40本の巡回列を復元して行・列の交点を整合させる解法ではなく、
盤面上の直接被覆を改善する局所探索です。最適性や上位相当の成績は主張しません。
公式本番の入力とローカル生成入力は異なり、順位表の総得点と単純比較はできません。
壁時計で探索を止めるので、同じ乱数seedでも負荷により結果が変動します。
