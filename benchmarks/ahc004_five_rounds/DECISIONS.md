# 開発時の採否（確認ケースを見る前）

主指標は各入力の全比較版・全repeatの最高点を分母とする相対点。
下記は意思決定時点の分母。最終レポートでは全5回を最新の共通分母で再計算する。

- Round 1: 変更行・列だけのAho-Corasick走査＋共通SA Runner。採用。
  baseline 969.373732 / 1000 → round1 991.765019 / 1000。
  平均点66,260,141 →67,702,144。全40測定合法、3秒以内。
- Round 2: 3bit一致数計算＋全800配置の候補比較。採用。
  round1 980.259573 →round2 986.029057 / 1000（それまでの全版を含む分母）。
  平均点67,931,416.35 →68,276,612.55。全40測定合法、3秒以内。
- Round 3: 初期構築650ms→150ms、残時間をSAへ配分。採用。
  round2 982.756074 →round3 987.756814 / 1000。
  平均点68,259,811.60 →68,571,749.95。全40測定合法、3秒以内。
- Round 4: 同点配置の選択をreservoir samplingで均等化。採用。
  round3 979.811897 →round4 985.936208 / 1000。
  平均点68,257,710.50 →68,687,856.05。全40測定合法、3秒以内。
- Round 5: 開始温度3→6（終了温度0.03は固定）。採用し、round5を最終候補に固定。
  round4 981.121346 →round5 984.839899 / 1000。
  平均点68,521,923.10 →68,762,542.80。全40測定合法、3秒以内。
  この決定後にseed 20–39を確認し、その結果を使った再調整はしない。
