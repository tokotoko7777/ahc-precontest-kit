# AHC035 練習用ソルバー

[AHC035 A - Breed Improvement](https://atcoder.jp/contests/ahc035/tasks/ahc035_a) の、提出可能な単一 `main.cpp` です。ローカルの `.hpp` には依存しません。

6×6 の畑へ36個の種を置くと、上下左右に隣り合う親から60個の子ができます。子の15成分は、それぞれ独立にどちらかの親から受け継がれます。これを10世代繰り返し、最後の世代で成分合計が最大の種を強くします。

## まず使う

提出時は `main.cpp` をそのままAtCoderへ貼り付けます。

```bash
g++ -std=c++17 -O2 main.cpp -o main
```

この問題は対話形式です。配布入力を `./main < in/0000.txt` のように直接渡しても動きません。ローカルでは[公式ツール](https://img.atcoder.jp/ahc035/F5dI2O6U.zip)の `tester` を間に入れます。

```bash
# 公式toolsディレクトリで一度だけ
cargo build --release --bin tester --bin vis

# 実行。mainへのパスは自分の環境に合わせる
./target/release/tester /path/to/main < in/0000.txt > out.txt

# 出力の合法性とスコアをもう一度確認し、vis.htmlを作る
./target/release/vis in/0000.txt out.txt
```

## やっていること

各世代で、次の3点を足した「盤面の良さ」を計算します。

1. **子の平均的な強さ**  
   ある辺から生まれる子の成分合計の期待値は、両親の成分合計の平均です。合計値の高い種を次数4の中央付近へ置くと、その種から多くの子を作れます。

2. **相補的な親による上振れ**  
   両親の成分差の二乗和平方根を加点します。得意な成分が異なる親を交配すると、良い側を多く受け継いだ子が生まれる余地があります。

3. **良い成分の保存**  
   選んだ36個が持つ成分別最高値を加点します。また、最高値と2番手の差が大きい希少成分を持つ種は、子を多く残せる中央へ寄せます。

最初は強い種を中央から置きます。その後、次の2操作を焼きなましで12,000回試します。

- 盤面内の2個を交換する
- 盤面の1個を、使っていない24個のどれかと交換する

乱数seedは世代番号と現在の種データだけから作るため、同じ対話入力なら同じ出力になります。時間計測に依存しません。

## 調整しやすい場所

`main.cpp` 冒頭の4定数だけで、探索量と評価のバランスを変えられます。

| 定数 | 初期値 | 大きくすると |
|---|---:|---|
| `SEARCH_STEPS` | 12000 | 交換を多く試すが遅くなる |
| `RISK_WEIGHT` | 0.70 | 成分差の大きい親を隣接させやすい |
| `COVERAGE_WEIGHT` | 4.0 | 成分別最高値を持つ種を選びやすい |
| `RARE_DEGREE_WEIGHT` | 2.5 | 希少な最高成分を中央へ置きやすい |

たとえば探索を軽くするなら、ソースを書き換えず次のようにも指定できます。

```bash
g++ -std=c++17 -O2 -DSEARCH_STEPS=3000 main.cpp -o main
```

## 単純解との比較

`-DSIMPLE_BASELINE` を付けると、毎世代ID 0〜35を行優先で置くだけの比較用解になります。

```bash
g++ -std=c++17 -O2 -DSIMPLE_BASELINE main.cpp -o baseline
```

## 検証

- `g++ -std=c++17 -O2 -Wall -Wextra -Wshadow -pedantic`：警告なし
- 公式tester：seed 0〜99の全ケースで合法に完走
- 公式visualizer：seed 0を再採点し `840426` で一致
- AddressSanitizer + UndefinedBehaviorSanitizer：seed 0, 37, 99で異常なし

この方針は、成分別最高値・希少度・相補的な隣接親を使うというAHC035のレビュー知見を参考にしつつ、期待値・成分差・最高値被覆を明示した独自実装です。レビューに記録された代表提出の最終スコアや各要素の比較結果は未確認なので、上の数値はこの実装を公式ローカルツールで測った結果だけを記載しています。
