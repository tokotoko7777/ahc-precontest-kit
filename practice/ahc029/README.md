# AHC029 practice

公式問題: [A - Business](https://atcoder.jp/contests/ahc029/tasks/ahc029_a)

`main.cpp` だけで提出できる、オンライン経営ゲームの練習例です。ローカルのheaderには
依存しません。

## 問題の要点

1000ターンの各ターンで、次の二つを順番に決めます。

1. 手札から方針カードを1枚使う。
2. 表示された候補から、使った場所へ補充するカードを1枚買う。

案件は残工数 `h` と報酬 `v` を持ちます。作業カードで `h <= 0` にすると `v` を受け取り、
新しい案件へ入れ替わります。カード購入費は最後の所持金から直接引かれるため、高性能でも
高すぎるカードを買い続けると得点が残りません。

投資カードは、これから出現する案件・カード・価格を全て2倍にします。早い投資は以後の
収益へ長く効きますが、終盤の投資は購入費を回収できません。

## 解法

### 1. 案件の効率を `v / h` で見る

通常作業カードの評価値を、おおよそ次の値にします。

```text
min(カードの仕事量, 案件の残工数) * v / h
```

ちょうど案件を完了できる場合は8%の小さなbonusを加えます。これにより、同程度の効率なら
早く現金化して次の案件を出せる手を選びます。

全体作業カードは、この値を全案件について合計します。手札内の全ての通常・全体作業カード
と対象案件を列挙し、最大値の行動を使います。最大でも手札7枚・案件8件なので全列挙で十分
高速です。

### 2. 明らかに悪い案件だけ中止する

中止カードは `v / h < 0.82` の最も効率が悪い案件へ使います。全案件中止は、悪い案件が
半数以上あるときほど高く評価します。中止にも1ターンを使うため、少し平均以下というだけ
では捨てません。

### 3. 投資は早期だけ優先する

投資レベルが20未満で残り150ターンより多ければ、手札の投資カードを最優先で使います。
購入候補の投資カードも同じ期間は優先します。

ただし残り300ターン以内では、投資費が現在資金の80%を超える場合は見送ります。終盤に
現金のほぼ全てを投資し、回収前に1000ターンが終わる失敗を防ぐためです。

### 4. 通常カードは割安品だけ買う

各購入候補を「今の盤面で使った場合の行動評価 − 価格×1.9」で比較します。候補0は必ず
無料の通常作業カードなので、高価な候補に十分な上積みがなければ安全に候補0を選べます。

投資カードは複利効果が大きいため、この通常カード評価とは別に扱います。

## 対話処理で重要な箇所

- 行動の `c m` を出した直後に `endl` でflushする。
- 更新後の案件、所持金、購入候補の順に読む。
- 買ったカードは、使用して空いた手札位置へ入れる。
- 投資カードを使った直後に投資レベルを1増やす。
- 作業対象を取らないカードでは必ず `m = 0` を出す。

## コードを読む順番

- `regular_work_value`: 通常作業1手の評価
- `choose_action`: 手札と対象案件の全列挙
- `purchase_value`: 通常購入候補の値段込み評価
- `choose_purchase`: 投資優先と無料候補へのfallback
- `main`: 公式の対話順序

## コンパイル

通常版:

```bash
g++ -std=c++17 -O2 main.cpp -o solver
```

公式サンプルと同じ「常にカード0を案件0へ使い、候補0を買う」比較版:

```bash
g++ -std=c++17 -O2 -DBASELINE_POLICY main.cpp -o baseline
```

## 公式ローカルツールでの確認

[公式テスタ・ビジュアライザ](https://img.atcoder.jp/ahc029/45e6da0b06.zip)でseed 0〜99を
実行しました。

- 全100ケースで1000ターン完走、対話エラー0件
- 通常版の平均絶対スコア: 1,439,550.62
- 通常版の幾何平均: 150,386.57
- 通常版の最小・最大: 4,296 / 28,067,706
- baselineの平均絶対スコア: 1,065.50
- baselineの幾何平均: 1,034.29
- 通常版とbaselineの勝/分/敗: 100 / 0 / 0
- 公式テスタ込みの平均wall time: 約0.03秒

絶対スコアは投資カードの出現回数によって桁が大きく変わります。そのため算術平均だけでなく
幾何平均とケースごとの勝敗も併記しています。seed 0〜9ではbaseline平均927.0に対し、通常版
平均1,027,968.8でした。

`-Wall -Wextra -Wshadow -pedantic` で通常版・baselineとも警告なしです。ASan・UBSanを
同時に有効にしたseed 0、37、99も1000ターン完走しました。seed 0の出力は公式
ビジュアライザでもスコア20,252として再確認しています。

## 知識コーパスとの関係

AHC029 reviewの「まず合法な即時評価で候補を絞る」「将来価値と投資回収期間を考える」という
構造を参考にしました。代表レビューの最終スコア対応は未確認という記録を維持しています。
この例は分布推定Monte Carloまでは入れず、初心者が変更しやすい決定的な貪欲として独自に
実装したものです。第三者の提出コードは使用していません。
