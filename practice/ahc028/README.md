# AHC028 - 文字列の重なり順 + キー位置 DP

## 問題を二つに分ける

この問題では、同時に次の二つを決める必要があります。

1. 200 個の単語をどの順でつなぐか。
2. 各文字を盤面上のどのキーで入力するか。

一度に両方を扱うと複雑になるため、この実装では「文字列」と「実際のキー位置」を別の層として扱います。

## 1. 単語を重ねて短い文字列を作る

単語 `a` の末尾と単語 `b` の先頭が一致する最大長を、全ペアについて前計算します。

例えば `ABCDE` の後ろへ `DEFGH` を置く場合、`DE` を共有して `ABCDEFGH` とできます。
順番に単語を追加すると、その時点の文字列の末尾は最後に追加した単語全体になるため、隣り合う単語の重なりだけで全単語を確実に含められます。

## 2. 固定した文字列を最小費用で入力する

同じ文字のキーは盤面に複数あります。文字列の各位置について、

`dp[今回使うキー] = min(dp[前回のキー] + Manhattan距離 + 1)`

を計算します。最後に親をたどれば、最小費用の座標列も復元できます。

盤面には 225 マス、各文字の出現数は平均約 9 個なので、この DP は十分高速です。

## 単語順の探索

単なる重なり文字数だけでなく、追加部分を盤面で入力する概算費用を単語ペアごとに前計算します。
初期解には次を使います。

- 入力順
- 全 200 通りの開始単語からの最近傍法
- 最良位置へ単語を挿入する貪欲法
- 上位候補から選ぶランダム化最近傍法

探索前半では、ペア概算費用に対して `swap`、`relocate`、区間反転を行います。
探索後半では次の処理を繰り返します。

1. ランダムに一つの単語を抜く。
2. 概算費用が良い挿入先を上位 3 個へ絞る。
3. 候補を実際の全文字 DP で評価する。
4. 改善手と、温度に応じた小さな悪化手を受理する。

概算だけでは「重なりは良いがキーが遠い」順番を選ぶ場合があります。最後に公式費用そのものを使うことで、そのずれを補正します。

## 合法になる理由

- 各単語は、直前の単語との最大重なりを除いた部分だけを追加するため、完成文字列の部分文字列として必ず現れる。
- 完成文字列は高々 `200 * 5 = 1000` 文字で、5000 回制限を超えない。
- 各文字について、実際にその文字が置かれている盤面内座標だけを DP 候補にする。

したがって、全 200 単語を含む合法な座標列を必ず出力します。

## 使い方

```bash
g++ -std=c++20 -O2 -pipe -Wall -Wextra -Wshadow main.cpp -o main
./main < input.txt > output.txt
```

提出時は `main.cpp` だけで動き、ローカルヘッダには依存しません。

検証用の切り替えもソース内にあります。

```bash
# 90 ms の短時間版
g++ -std=c++20 -O2 -DLOCAL_SHORT_TIME main.cpp -o main-short

# 入力順・重なりなし・最近キーを選ぶ単純基準解
g++ -std=c++20 -O2 -DAHC028_BASELINE main.cpp -o main-baseline

# 入力順のまま、重なりと位置 DP だけを使う中間解
g++ -std=c++20 -O2 -DAHC028_INPUT_ORDER_DP main.cpp -o main-input-dp
```

## 計算量

完成文字列長を `L`、1文字当たりのキー候補数を `P` とすると、位置 DP は `O(L * P^2)` です。
単語順探索は 1.85 秒で打ち切り、常にそれまでの最良順を保存します。

## 公式ツールでの検証

公式ローカルツールの seed 0--9 を同じ入力集合で比較しました。

| 方法 | 平均点 | 最小 | 最大 |
|---|---:|---:|---:|
| 入力順・重なりなし・最近キー | 5675.7 | 5510 | 5860 |
| 入力順・最大重なり・位置 DP | 6380.2 | 6277 | 6572 |
| 単語順探索 + 位置 DP | **7299.2** | 7219 | 7398 |

完成版の seed 0--9 の点数は
`7398, 7225, 7370, 7337, 7229, 7333, 7250, 7219, 7324, 7307`
でした。単純基準解に全 10 ケースで勝ち、平均は約 28.6% 改善しました。

- 通常版: seed 0--9 が全て合法、典型 wall time 1.86 秒、最大常駐メモリ約 4.6 MiB
- 90 ms 版: seed 0--99 が全て合法、平均 7184.21 点、範囲 6938--7350
- `-Wall -Wextra -Wshadow -Wconversion -pedantic`: 警告なし
- AddressSanitizer + UndefinedBehaviorSanitizer: seed 0, 73 で指摘なし

90 ms 版の平均は別の 100 ケース集合に対する値なので、通常版の seed 0--9 平均との直接比較には使っていません。
