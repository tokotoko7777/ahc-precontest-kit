# AHC009 practice

公式問題: [A - Robust Shortest Path](https://atcoder.jp/contests/ahc009/tasks/ahc009_a)

`main.cpp` だけで提出できる、失敗確率付き経路の練習例です。

## 問題の要点

20×20の迷路で、長さ200以下の `UDLR` を1本出力します。ただし各文字は確率 `p` で
忘れられ、そのターンは移動しません。壁へ進もうとした場合も現在地に残ります。

早いターンに初めてゴールへ着く確率を高くすると得点が上がります。単一の「たぶん通る
軌跡」だけを見ると、失敗後にどこへいるかを評価できない点が難しさです。

## 解法

### 1. 確率をそのままDPする

`evaluate_commands` は、各マスにいる「まだゴールしていない確率」を持ちます。1文字ごとに
次の2通りへ確率を配ります。

- 確率 `p`: 文字を忘れて同じマス
- 確率 `1-p`: 指定方向へ移動。壁なら同じマス

ゴールへ入った確率は盤面から取り除き、そのターンの価値を掛けて加算します。これで
Monte Carloのぶれを使わず、出力列の公式期待得点を厳密に比較できます。

### 2. 頑丈な初期解を複数作る

Dijkstra法の辺重みを少しずつランダム化し、形の違う経路を作ります。各経路の文字を
およそ `1/(1-p)` 倍まで複製し、失念への余裕を持たせます。短時間で複数候補を正確に
評価し、最良候補だけを次へ渡します。

### 3. 可変長の焼きなまし

文字列へ次の近傍を混ぜます。

- 同じ文字を複製
- ランダムな文字を追加
- 1文字を削除
- 方向を変更
- 1文字を別位置へ移動

毎回 `evaluate_commands` で公式期待値を再計算します。改善解は必ず採用し、序盤だけは
少し悪い解も採用して局所解から抜けます。`current_commands` と `best_commands` は別に
保存するため、最後に途中の最良解を失いません。

## 読む時の目印

- `Maze::move_to`: 壁判定済みの遷移先。壁なら自分自身
- `evaluate_commands`: 未到達確率の前向きDP
- `make_shortest_path`: ランダム辺重みDijkstra
- `add_redundancy`: 失敗率を見越した初期文字列
- `mutate_commands`: add/delete/change/relocate近傍

## 計算量

長さを `L`、確率が残るマス数を `V` とすると、1回の評価は `O(LV)`、最大でも
`200×400`です。確率が0でないマスだけを列挙し、配列全体の初期化も避けています。

## 公式ローカルツールでの確認

[公式ローカルツール](https://img.atcoder.jp/ahc009/cf3f791aac0f80374c60.zip)を使い、
付属seed 0〜9を採点しました。

- 全10ケースで出力長200、形式エラー0件
- 平均得点: 74,011,284.4
- 最小得点: 43,439,955
- 最大得点: 87,794,854
- 初版の多点スタート＋全再計算SA（平均73,374,729.3）に対して約0.87%改善
- 10ケース中8勝・2敗

通常版は1ケース約1.87秒で探索を止めます。seed 0はASan・UBSanを同時に有効化した
実行でも完走し、公式ビジュアライザで形式と得点を確認しました。

## 注意

- 時間で探索を止めるため、CPU速度によって反復数と最終出力は変わります。
- `p` の枝と `1-p` の枝の両方が同じマスへ戻る場合も、確率を2回足す必要があります。
- ゴール到着済みの確率を次ターンへ残すと二重加点になるので、DPから取り除きます。
- 研究資料の考え方を参考にした独自の初心者向けC++実装で、第三者提出コードの転載では
  ありません。
