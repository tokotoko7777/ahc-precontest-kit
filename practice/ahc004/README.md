# AHC004 practice

公式問題: [A - Alien's Genome Assembly](https://atcoder.jp/contests/ahc004/tasks/ahc004_a)

`main.cpp` だけで提出できる、過去AHCを使ったライブラリ実戦例です。

## 問題の要点

20×20のトーラス盤面を `A`〜`H` と空きマス `.` で作ります。入力文字列が、
左右または上下へ巡回する連続部分列として現れれば得点になります。入力は、未知の
ランダムな20×20盤面から切り出して生成されています。制限時間は3秒です。

## 使用したパーツ

- `Timer`
- `Random`
- `suffix_prefix_overlap` (`sequence-overlap.hpp`)

パーツはローカルヘッダとして参照せず、`main.cpp` の上部へ直接貼っています。

## 独自解法

最初に、別の入力文字列へ完全に含まれる短い文字列をまとめます。残った長い文字列は、
次の優先度で空の盤面へ1本ずつ置きます。

1. 既存の同じ文字と多く重なる配置
2. 新しく埋めるマスが少ない配置
3. まだ空いている行・列へ分散する配置

順序と同点配置を変えた多点スタートを行い、入力文字列を最も多く含む盤面を残します。

後半は、まだ含まれていない文字列を盤面へ上書きする焼きなましです。上書きで変わるのは、
変更マスを通る横・縦の巡回部分列だけです。長さ2〜12の各窓を3bit/文字の整数へ変換し、
入力文字列の出現数を差分更新します。毎回全入力を探し直す処理を避けることで、3秒内でも
大きな近傍を何度も試せます。

## この練習で追加した汎用パーツ

`sequence-overlap.hpp` を追加しました。1つ目の列の末尾と2つ目の列の先頭が一致する
最大長と、最大限重ねた連結結果を取得できます。`string`だけでなく`vector<int>`にも
使えます。

## 公式入力での確認

公式配布のseed 0〜9を `-O3 -march=native` で各1回実行し、公式visualizerで採点しました。

- 不正出力: 0ケース
- 平均スコア: 66,364,169.90
- 最小スコア: 54,214,876
- 最大スコア: 93,516,699

seed 0では、前半の重ね合わせだけの初期版55,929,919点に対し、差分更新付き探索を
加えた版は70,485,175点でした。実時間で反復数が変わるため得点は多少変動します。

## 注意

- 未知の元盤面や上位解法を復元するものではなく、入力文字列の直接被覆数を改善します。
- 40本の元の巡回列を明示的に復元して行列の交点を整合させる処理は未実装です。
- `sequence-overlap.hpp` は短い列向けの単純な `O(min(N,M)^2)` 実装です。長い列を
  大量に比べる場合はZ algorithmやrolling hashを選びます。
