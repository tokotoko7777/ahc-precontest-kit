# 11. 確率・推定・情報収集

[詳細編の目次](README.md) · [用語](GLOSSARY.md) · [出典一覧](SOURCES.md)

未知の値を1つに決めつけず、分布・区間・複数仮説で持ちます。観測で何が分かり、何はまだ分からないかを明確にし、次に何を測るか、どの行動を選ぶかへつなげます。

説明用の小例と、提出コードで確認した具体例を分けて記載しています。適用効果は未測定で、検算と練習はこれから確かめるための課題です。

## D213. 低ランク共分散更新

観測で変化する相関を、毎回巨大な行列へ書き込む代わりに、少数の補正ベクトルとして保持します。

1回の線形観測による補正が外積の形なら、観測1回につき1組の情報を足せます。観測数が増えると補正列も増えるため、いつまでも一定費用ではありません。

<a id="example-23016921-01"></a>
### コードでの具体例：密共分散を観測ごとのrank-1補正列で表す

初期カーネルに対して補正ベクトルと係数を追加し、疎な観測Hとの積から平均と対角分散を更新する。

**適用条件・落とし穴。** 観測数が制限された高次元線形推定に向く。履歴数とともに計算量が増える。

**検算と練習。** 小次元の密Kalman更新と平均・共分散対角・尤度を比較する。

出典: [AHC003 / 提出 23016921](https://atcoder.jp/contests/ahc003/submissions/23016921) · `Variance / kalman_correct_lazy` · L658–L700, L727–L747。 [収録情報](SOURCES.md#submission-23016921)

## D214. モデル平均

どのモデルが正しいか決め切れないとき、複数の予測を重み付きで混ぜます。観測に合うモデルの重みを増やします。

予測10の重みが0.8、予測20が0.2なら平均予測は12です。モデル間の違いも不確実性に含めるかを考えます。

<a id="example-23016921-02"></a>
### コードでの具体例：異なる相関カーネルを尤度で混ぜる

共通成分と独立成分の分散や距離相関が異なる8モデルを用意し、観測対数尤度から混合重みを算出する。

**適用条件・落とし穴。** 事前構造を一つに決められない場合に候補モデルを並走させる。

**検算と練習。** 単独モデルとの予測誤差を比較し、重み総和が1になるか確かめる。

出典: [AHC003 / 提出 23016921](https://atcoder.jp/contests/ahc003/submissions/23016921) · `all_models / mix_ps` · L1154–L1179, L1262–L1300。 [収録情報](SOURCES.md#submission-23016921)

## D215. 不確実性ボーナス

費用が不確かな場所を、平均より少し安く見積もって試すと、未観測領域を探索する動機になります。

平均10・標準偏差3へ係数1の割引をすると評価7です。これは楽観的な探索評価であり、実際の費用予測10とは区別します。

<a id="example-23016921-04"></a>
### コードでの具体例：平均から標準偏差に比例した割引を引く

混合前のモデルごとの推定平均からgamma×標準偏差を引き、ターン進行でgammaを減らして経路を選ぶ。

**適用条件・落とし穴。** 観測価値と現在の距離損を同じコストへ入れる。負の辺費用と探索器の前提は別途確認が必要。

**検算と練習。** 割引なしとの総費用・予測誤差の推移を比較する。

出典: [AHC003 / 提出 23016921](https://atcoder.jp/contests/ahc003/submissions/23016921) · `get_cost / gamma` · L1204–L1212, L1467–L1519。 [収録情報](SOURCES.md#submission-23016921)

## D216. 観測ノイズの分解

観測誤差が何に比例して増えるかを分けると、信頼度を入力ごとに調整できます。

経路が長いほど独立な誤差が積み重なる項と、全費用に比例してずれる項は違います。ノイズを過小評価すると、1つの観測を信じすぎます。

<a id="example-23016921-06"></a>
### コードでの具体例：経路総費用と経路長から観測分散を作る

通った辺だけを疎ベクトルへ入れ、観測費用の二乗に比例する項と辺数比例の項をノイズ分散へ足す。

**適用条件・落とし穴。** 総和観測の相対誤差と要素別誤差を分けて扱う。

**検算と練習。** 短路・長路・高費用路で残差の分散が仮定と整合するか確認する。

出典: [AHC003 / 提出 23016921](https://atcoder.jp/contests/ahc003/submissions/23016921) · `sp_obs_matrix / r` · L1575–L1607, L1645–L1650。 [収録情報](SOURCES.md#submission-23016921)

## D217. 将来シナリオのサンプリング

未知の未来を1つに決めず、複数のあり得る未来を乱数で作り、判断の結果を比べます。

未来の辺が安い場合と高い場合を試し、現在の辺を買う価値を見積もります。すでに観測した事実まで引き直さないことが大切です。

<a id="example-27880973-01"></a>
### コードでの具体例：未知の辺重みだけを84回引き直す

確定済み成分は固定し、未来の各辺の長さを座標距離から乱数生成する。

**適用条件・落とし穴。** 逐次採否で未来の分布を近似できる場合に使う。分布仮定の外れに弱い。

**検算と練習。** 既知辺が再サンプルされないことと、標本数別の採否分散を確認する。

出典: [AHC007 / 提出 27880973](https://atcoder.jp/contests/ahc007/submissions/27880973) · `main sampling loop` · L66–L75。 [収録情報](SOURCES.md#submission-27880973)

## D218. 種類別の確率伝播

対象の種類で動き方が違うなら、確率分布も種類別に進めてから合計します。

1ターンに1歩動く対象と3歩動く対象を、同じ1回の遷移では表せません。小さな確率を省く場合は、捨てた質量による誤差も生じます。

<a id="example-29654603-06"></a>
### コードでの具体例：移動速度別に複数step進めてターン境界で合算する

種類ごとの速度と整数確率を用い、小さい質量を省いて予測する。特定種類には直近移動履歴を候補へ重複追加する。

**適用条件・落とし穴。** 厳密な確率モデルではなく、行動履歴と移動速度を組み込む近似予測。

**検算と練習。** 省略質量と予測距離別の誤差を測り、履歴重みの過剰適合を確認する。

出典: [AHC008 / 提出 29654603](https://atcoder.jp/contests/ahc008/submissions/29654603) · `updatePetsProb` · L1060–L1117。 [収録情報](SOURCES.md#submission-29654603)

## D219. 確率質量の伝播

現在位置が不確かなときは、1つの推定位置ではなく、各セルにいる確率を更新できます。

成功率0.8の右移動なら、各セルの質量の0.8を右へ、0.2を元へ送ります。壁に当たる場合の残留も入れ、全質量が保存されるか検算します。

<a id="example-30423648-03"></a>
### コードでの具体例：成功・失敗・壁の遷移を全セルで計算する

各時刻の全セル確率を次時刻へ送り、成功なら隣へ、失敗や壁なら現在位置へ質量を残す。

**適用条件・落とし穴。** 状態数が小さい確率的操作ならMonte Carloなしで期待値を評価できる。

**検算と練習。** 小盤面の経路事象の全列挙と確率総和を比較する。

出典: [AHC009 / 提出 30423648](https://atcoder.jp/contests/ahc009/submissions/30423648) · `calc_score` · L393–L433。 [収録情報](SOURCES.md#submission-30423648)

## D220. 区間観測

成功した観測が正確な値を返すとは限りません。分かるのが上下限なら、区間として保存します。

累積パワー80では壊れず、120で壊れたなら、硬さはその間です。中点100は推定値であり、測定された真値ではありません。

<a id="example-39142737-01"></a>
### コードでの具体例：破壊したときの累積パワー区間で硬さを保持する

最後の打撃前後の累積値をlo/hiへ保存し、区間中点を見積りに用いる。試すパワーごとに余剰破壊量と回数費用Cを比較する。

**適用条件・落とし穴。** 閾値到達でしか値が分からない観測。未破壊時の区間を確定した硬さと混同しない。

**検算と練習。** 既知硬度のシミュレータで区間包含と総費用を確認する。

出典: [AHC018 / 提出 39142737](https://atcoder.jp/contests/ahc018/submissions/39142737) · `dig / find_best_power` · L135–L175。 [収録情報](SOURCES.md#submission-39142737)

## D221. 近傍からの推定

近くの値が似ると期待できるなら、直前の観測を次の初期推定に使えます。

隣の硬さが約100なら、最初から小さく刻むより100付近を試せます。ただし急な境界では外れるため、失敗後の追加量や推定の信頼度を調整します。

<a id="example-39142737-05"></a>
### コードでの具体例：直前セルの硬さを初撃に使い、未破壊なら小刻みに進む

隣接セルの区間推定で初撃を大きくし、追加打撃は基準パワーの0.45倍へ落とす。近傍の硬さでも区間を補正する。

**適用条件・落とし穴。** 空間相関が強い地形。近傍補正は経験則で、真の硬さを含む区間保証ではない。

**検算と練習。** 急な硬度境界を含め、過剰打撃量と打撃回数を別に計測する。

出典: [AHC018 / 提出 39142737](https://atcoder.jp/contests/ahc018/submissions/39142737) · `main / LAST_V_MUL` · L462–L489。 [収録情報](SOURCES.md#submission-39142737)

## D222. 飽和観測の尤度

観測が上限・下限で切られると、端の値は1点の結果ではなく、その外側すべてをまとめた結果です。

本当は−5でも0へ丸めて表示されるなら、観測0の尤度は「0以下になる確率」です。0ちょうどの密度だけを使うと、仮説の重みを誤ります。

<a id="example-44783436-02"></a>
### コードでの具体例：0と上限1000の観測には裾確率を使う

通常値には確率密度、クリップ端点には以下・以上の確率を乗じて事後分布を更新する。端点の観測を単なる点密度として扱わない。

**適用条件・落とし穴。** センサ値が上下限へ丸め込まれる推定。裾の質量を潰すと極端な温度の候補を誤評価する。

**検算と練習。** 乱数生成したクリップ観測の頻度と尤度を比較する。

出典: [AHC022 / 提出 44783436](https://atcoder.jp/contests/ahc022/submissions/44783436) · `Pred::Update` · L2763–L2787, L1685–L1709。 [収録情報](SOURCES.md#submission-44783436)

## D223. 競合する対応先の補正

各対象を独立に推定すると、全員が同じ対応先を有望とするなど、全体の排他制約に矛盾することがあります。

2入口が同じ1出口を選べないなら、候補の集中を補正します。ただし簡易な確率補正が、厳密な1対1対応の事後分布と一致するとは限りません。

<a id="example-44783436-03"></a>
### コードでの具体例：出口ごとのオッズ和で候補確率を補正する

入口ごとの独立な事後Qを持ちつつ、同じ出口に集中するオッズ和でProbを補正する。更新行の旧寄与を引いて新寄与を足す。

**適用条件・落とし穴。** 一対一対応の競合を安価に反映したい場合。厳密な置換事後分布や割当最適化ではない。

**検算と練習。** 行列の確率性と重複割当率を測り、厳密割当との違いを調べる。

出典: [AHC022 / 提出 44783436](https://atcoder.jp/contests/ahc022/submissions/44783436) · `Pred::Q_j_sums` · L2750–L2760, L2769–L2787, L2806–L2809。 [収録情報](SOURCES.md#submission-44783436)

## D224. 候補を分離する観測

観測位置は「値が大きい場所」ではなく、「残る仮説を見分けやすい場所」から選びます。

候補A,Bが同じ値を予測する場所を測っても区別できません。予測差とノイズ、測るための移動費用を合わせて比較します。

<a id="example-44783436-04"></a>
### コードでの具体例：候補ペアの紛らわしさと観測費用の積を最小化する

自信の低い入口を選び、位置ずれごとに候補確率の積と温度の尤度を足す。距離費用を掛け、途中和で勝てない候補を打ち切る。

**適用条件・落とし穴。** 追加観測で候補を分離したい場合。これはエントロピーそのものではなく代理指標である。

**検算と練習。** 観測前後の識別誤り減少と費用を測り、固定位置観測と比べる。

出典: [AHC022 / 提出 44783436](https://atcoder.jp/contests/ahc022/submissions/44783436) · `SQRT::Run` · L2974–L3060。 [収録情報](SOURCES.md#submission-44783436)

## D225. 仮説集合の逐次拡張

すべての仮説を最初から列挙できない場合、現在有望な仮説の近くを探して候補集合を増やします。

観測に合う配置を親として一部を動かし、未登場の配置だけ追加します。候補集合の外にも真の答えがある可能性を忘れないようにします。

<a id="example-50447114-01"></a>
### コードでの具体例：尤度に比例して親配置を選び未出現の近傍を蓄える

対数尤度から累積重みを作り、二分探索で親を選んで複数油田を変更する。新しいハッシュだけ候補集合へ追加する。

**適用条件・落とし穴。** 複数の有力仮説を残す推定。正規のMCMC受理式とは異なり、厳密な事後サンプルとは断定しない。

**検算と練習。** 小さな全列挙可能問題で候補の被覆率と重み分布を比較する。

出典: [AHC030 / 提出 50447114](https://atcoder.jp/contests/ahc030/submissions/50447114) · `generate_states` · L1393–L1459。 [収録情報](SOURCES.md#submission-50447114)

## D226. 情報量あたりの観測費用

1回の観測が減らす不確実性を、観測費用で割って比較します。

情報量2・費用1の観測と、情報量3・費用3なら、効率は前者が高くなります。集合の大きさで費用が変わる規則では、その式も評価へ入れます。

<a id="example-50447114-02"></a>
### コードでの具体例：相互情報量に観測集合サイズの平方根を掛ける

事前エントロピーから観測後の条件付きエントロピーを引き、集合観測の費用1/sqrt(k)で割った指標を使う。

**適用条件・落とし穴。** 安い集合観測が可能な能動推定。情報利得がモデル化した仮説集合に依存する。

**検算と練習。** 選択照会の予測情報利得と実際の候補減少量を比較する。

出典: [AHC030 / 提出 50447114](https://atcoder.jp/contests/ahc030/submissions/50447114) · `State::calc_score` · L2328–L2335。 [収録情報](SOURCES.md#submission-50447114)

## D227. 単一仮説の反証

手元の候補が1個になっても、真の答えが候補生成で漏れた可能性があります。最後の候補を反証できる観測を残します。

候補が「ここに資源がある」と予測する未観測セルを調べ、違えば候補集合そのものを見直します。候補数1と確実性100%は別です。

<a id="example-50447114-07"></a>
### コードでの具体例：候補が1つでも推定された油田セルを追加確認する

回答が通らなければ、候補が油ありと予測する未観測セルを優先して観測する。候補生成が見逃した別解の存在を前提に反証を進める。

**適用条件・落とし穴。** 候補集合が狭まりすぎた推定。候補1つという内部状態を真の確定と混同しない。

**検算と練習。** 誤った単一候補を与えたとき、何回の照会で矛盾へ到達するか測る。

出典: [AHC030 / 提出 50447114](https://atcoder.jp/contests/ahc030/submissions/50447114) · `SingleDigSolver / choose_next_pos` · L2684–L2706, L2736–L2771。 [収録情報](SOURCES.md#submission-50447114)

## D228. 和の観測からの推定

個々の値を直接測れなくても、複数の和を測ることで値を推定できます。

x+y≈10、y+z≈12のような観測を集め、予測和との誤差を小さくします。観測の組が足りなければ個別の値を一意に決められない点に注意します。

<a id="example-60609745-01"></a>
### コードでの具体例：長さの和を観測する配置を作って寸法を最小二乗で補正する

元の単独寸法観測と、積み重なった長さの和の観測をまとめ、誤差二乗和の勾配を各寸法へ配る。

**適用条件・落とし穴。** 単体を直接精密測定できず組合せの合計が観測できる場合。どの辺が外形を作るかの推定にも依存する。

**検算と練習。** 真の寸法既知の模擬入力で推定誤差と外形予測誤差を測る。

## D229. 誤差余裕つき配置

推定した寸法の誤差を見込み、余裕を持った配置を評価します。

独立な誤差の分散が4と9なら、合計の分散は13、標準偏差は√13です。誤差が相関する場合は共分散も必要で、単純加算だけでは不足します。

<a id="example-60609745-03"></a>
### コードでの具体例：累積分散の平方根を横幅の安全余裕にする

積み重ねる寸法の分散を加算し、隣帯との位置比較を幅±係数×標準偏差で行う。曖昧な重なりは空き領域の損失として評価する。

**適用条件・落とし穴。** 測定誤差で配置の接触関係が変わる問題。独立誤差の近似と経験的な係数に依存する。

**検算と練習。** ノイズを再生成した配置で衝突関係・外形のばらつきを測る。

## D230. 構造応答から制約抽出

問い合わせが距離そのものを返さなくても、返された構造から大小関係を取り出せる場合があります。

MSTの非木辺より、木上の対応経路の最大辺が重くなることはありません。こうした比較を制約として集め、隠れた座標の候補を絞ります。

<a id="example-64611675-01"></a>
### コードでの具体例：返された木の経路上の辺と非木辺を比較制約にする

問い合わせMSTの非木辺の両端から木を登り、経路上の辺との大小関係を登録。既知の距離範囲で自明なものと重複を除く。

**適用条件・落とし穴。** 実数距離が返らない観測でもMSTの交換性質を利用できる。等距離の扱いは判定器と合わせる。

**検算と練習。** 小さな座標例で全制約が観測MSTに整合するか検証する。

## D232. 非正規化分布

生存した確率の総量を残すと、死亡した分も含めた期待値を計算できます。毎回合計1へ戻すと生存率を失います。

分布の合計が0.7なら、残り0.3はすでに失敗した質量です。生存条件付きの位置分布が欲しいときだけ、0.7で割って区別します。

<a id="example-67393589-01"></a>
### コードでの具体例：生存条件で割り直さず確率質量の消失を追う

石位置の確率を生存確率から引き、残った質量をそのまま移動させる。各時刻の生存確率の和を期待報酬にする。

**適用条件・落とし穴。** 吸収・終了を含む有限過程向け。条件付き分布と混ぜると二重に生存確率を掛けてしまう。

**検算と練習。** 小盤面の全分岐列挙と確率総和・期待報酬を照合する。

**適用条件・落とし穴。** 期限を持つオンライン資源割当向け。需要分布と指数減衰はモデル仮定であり万能ではない。
