# AHC039 - 上下の境界を動かす、必ず単純な直交多角形

[公式問題文](https://atcoder.jp/contests/ahc039/tasks/ahc039_a) / [公式ローカルツール](https://img.atcoder.jp/ahc039/KNtTkgAy.zip)

## 問題を単純化する

サバを `+1`、イワシを `-1` の点と考えます。多角形の中にある点の重みの合計を大きくすればよく、公式スコアは

```text
max(0, 重みの合計 + 1)
```

です。

任意の直交多角形を直接変更すると、自己交差、穴、複数領域などの判定が難しくなります。この実装では、各x方向の列で「内側にするy区間は1個だけ」と決めます。

```text
high[x]  ┌──── 多角形の内側 ────┐
         │                        │
low[x]   └────────────────────────┘
```

隣り合う列の区間が1マス以上重なる、という条件も守ります。この形はx方向の直線と高々1区間で交わるため、穴や自己交差がありません。縦横を入れ替えた同じ探索も行い、y方向に細長い形も拾います。

## 点を格子へ集約する

盤面を最終的に `200 × 200` の格子へ分け、各セルへ

```text
そのセルのサバ数 - そのセルのイワシ数
```

を保存します。列ごとの累積和も作るので、`low[x]` から `high[x]` までの得点を `O(1)` で求められます。

内部の格子線は、魚のx座標・y座標と一致しない整数へ少しだけずらします。そのため「格子セルに含まれる点」と「出力多角形に含まれる点」が境界上の点によって食い違いません。

## 単純 baseline: 最良長方形

まず、格子上の全軸平行長方形から重み和が最大のものを探します。

上下端を固定すると、各列の重みが求まります。残りは一次元最大部分配列なのでKadane法で左右端を決められます。計算量は `O(G^3)` です。

`AHC039_RECTANGLE_BASELINE` を定義すると、この長方形だけを出力します。

## 多解像度の境界探索

いきなり200分割を探索せず、次の順で細かくします。

1. `25 × 25`
2. `50 × 50`
3. `100 × 100`
4. `200 × 200`

細かい格子線は最初に全部作り、粗い格子ではその一部だけを使います。解像度を2倍にするときは、1列をそのまま2列へ複製します。したがって、細分化直後の多角形は前段階と全く同じ形・得点です。各段階の最良長方形とも比較し、良い方から探索を続けます。

焼きなましでは次の変更を行います。

- 1～8列の下境界を1マス動かす。
- 1～8列の上境界を1マス動かす。
- 1～8列の上下を同時に動かす。
- 左端・右端へ1列追加する。
- 左端・右端を1列削除する。
- 全列の上端または下端を同時に動かす。

隣接区間が重ならない変更と、周長400,000を超える変更は即座に捨てます。評価はまず魚の重み和を比較し、同点なら周長が短い方を好みます。最終200分割だけは異なる乱数列で2回探索します。

固定反復・固定乱数seedなので、同じ入力には同じ答えを返します。

## 出力が合法になる理由

各列の区間は空ではなく、隣接列の区間は正の幅で重なります。下端を左から右へ、右端を上へ、上端を右から左へたどると、交差しない1本の閉じた輪郭になります。

列数は最大200です。1つの列境界で増える頂点は最大4個なので、頂点数は最大800であり、上限1000以下です。各変更後に周長を正確に再計算し、400,000以下だけを受理します。出力直前にも生成した頂点列から周長を再計算して内部値との一致を確認しています。

全頂点は格子線上なので整数かつ `0..100000` の範囲内で、全辺は水平または垂直です。

## 計算量

最終格子幅を `G=200`、各段階の反復数を `I` とします。

- 点の格子集約: `O(N log G)`
- 最良長方形: 各解像度で `O(G^3)`
- 1回の近傍評価: `O(G)`
- 焼きなまし: `O(IG)`
- メモリ: `O(G^2)`

差分更新も可能ですが、`G<=200` なら全列を再確認しても十分高速です。合法性の復元漏れを避け、初心者が追いやすい方を選びました。

## コンパイルと使い方

提出には `main.cpp` だけを使います。外部ヘッダへの依存はありません。

```bash
g++ -std=c++20 -O2 -Wall -Wextra -Wshadow -Wconversion -pedantic -Werror main.cpp -o main
./main < in.txt > out.txt
```

公式ツールでは次のように採点できます。

```bash
cargo build --release --bin vis
./main < in/0000.txt > out.txt
./target/release/vis in/0000.txt out.txt
```

長方形baselineは次のように作ります。

```bash
g++ -std=c++20 -O2 -DAHC039_RECTANGLE_BASELINE main.cpp -o baseline
```

## 知識コーパスについて

Knowledge map、AHC039レビュー、差分評価、焼きなましの4か所だけを参照しました。AHC039レビューでは、粗い二値格子から始める多解像度探索、境界変更、格子内点数の集約が確認されています。

一方、レビュー対象提出の最終スコア対応は未確認で、Rust提出の自動静的タグも未対応と記録されています。この不確実性は維持しています。本実装は任意セル集合を再現せず、合法性を説明しやすいx単調な列区間へ独自に制限しました。第三者コードは使用していません。
