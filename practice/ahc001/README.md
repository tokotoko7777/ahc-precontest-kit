# AHC001 practice

公式問題: [A - AtCoder Ad](https://atcoder.jp/contests/ahc001/tasks/ahc001_a)

`main.cpp` だけで提出できる、過去AHCを使ったライブラリ実戦例です。

## 使用したパーツ

- `BatchedTimer`
- `Random`
- `AxisAlignedRectangle`

パーツはローカルヘッダとして参照せず、`main.cpp` の上部へ直接貼っています。

## 独自解法

各希望点を表す1×1矩形から始めます。希望点はすべて異なるため、この初期解は必ず合法です。
ランダムに1社を選び、上下左右への拡張候補を試します。

- 希望面積へ近づく複数の拡張幅を試す
- 盤面外へ出る候補は不採用
- 他矩形と正の面積で重なる候補は不採用
- その会社の満足度が上がる場合だけ採用

縮小や破壊・再構築は行わず、探索中ずっと合法性を保つ単調な局所改善です。

## この練習で追加した汎用パーツ

`axis-aligned-rectangle.hpp` を追加しました。座標型を選べる半開矩形で、幅、高さ、
面積、点包含、正の面積での重なりを判定できます。辺が接するだけなら重なりません。

## 公式ツールでの確認

公式配布のseed 0〜9で全矩形の境界・点包含・非重複を確認しました。
