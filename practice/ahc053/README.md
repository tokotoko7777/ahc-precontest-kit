# AHC053 練習解答: 共有する2進カード

提出するのは [`main.cpp`](./main.cpp) だけです。ローカルのヘッダやライブラリには依存しません。

## 問題を短く整理

最初に500枚のカードへ正の整数を書きます。その後、50個の目標値 `B_i` が分かるので、各カードを高々1個の山へ割り当てます。

- 各 `B_i` はおよそ `10^15`
- 山 `i` の合計を `B_i` に近づける
- 使わないカードは捨ててよい
- カードの値は、目標値を見る前に決めなければならない
- Scoreは各山の絶対誤差が小さいほど高い

公式問題文: <https://atcoder.jp/contests/ahc053/tasks/ahc053_a>

## 基準解

500枚を同じ値にし、10枚ずつ50個の山へ配ります。各山の合計は目標区間の中央付近になります。

同じファイルから基準解を出すには `AHC053_BASELINE` を定義します。

```bash
g++ -std=c++17 -O2 -DAHC053_BASELINE main.cpp -o baseline
./baseline < in.txt > out.txt
```

## この解法

### 1. 各山専用の土台を置く

最初の50枚はすべて `L` にします。目標値が分かったら、カード `i` を必ず山 `i` に置きます。

これで残りの仕事は、各山について `B_i - L` を作ることだけになります。

### 2. 残り450枚を共有の2進カードにする

15種類の値を、おおよそ次の比率で作ります。

```text
1, 2, 4, 8, ..., 16384
```

15種類を1枚ずつ自由に選べれば、0から約 `U-L` までを細かく表せます。ただし50山すべてへ各種類を1枚ずつ用意すると750枚必要です。そこで同じ値のカードを27〜32枚ずつだけ作り、必要な山同士で共有します。

小さいカードは不足しても別の組合せで直しやすいため27枚、大きいカードほど32枚へ増やしています。全種類の枚数合計はちょうど450枚です。

表現範囲は `U-L` の103.65%にします。少しだけ上へ広げることで、最大付近の目標にも届きやすくしています。

### 3. 一番近い部分集合を桁DPで探す

各山について、15種類のカードを使う・使わないの組合せを選びます。

全 `2^15 = 32768` 組の合計値を前計算します。特定の種類を使用禁止にした場合も、2進数としての下限・上限を持つ小さな桁DPにより、目標以下で最大の組合せと目標以上で最小の組合せを探せます。

### 4. カード不足を修理する

最初は各山を独立に決めるため、ある種類を用いる山が用意した枚数を超えることがあります。

不足中のカードを外した候補を各山について作り、

```text
誤差の増加量 / 解消できる不足枚数
```

が小さい変更から採用します。必ず不足カードを単純に外す候補も含めるため、修理は停止し、最後は必ず枚数制限を満たします。

### 5. 1山・2山の交換で誤差を戻す

不足修理後には、余っている種類が生まれます。

- 1山だけ別の組合せへ変更
- 2山を同時に変更し、一方が空けたカードを他方で使用

を試し、総絶対誤差が減り、全種類の枚数制限も守る場合だけ採用します。

## コンパイルと実行

```bash
g++ -std=c++17 -O2 -Wall -Wextra -Wshadow -Wconversion -pedantic \
  main.cpp -o main
./main < in.txt > out.txt
```

```bash
cargo run --release --bin tester ./main < in.txt > out.txt
```

乱数は使っていないため、同じ入力には毎回同じ出力になります。

## 検証結果

公式配布のseed 0〜99を、基準解と完成版の両方で採点しました。Scoreは大きい方が良い問題です。

| 方式 | 合法 | 平均Score | 合計Score | 最小 | 最大 |
|---|---:|---:|---:|---:|---:|
| 同じ値を10枚ずつ配る基準解 | 100 / 100 | 315,413,169.29 | 31,541,316,929 | 311,342,724 | 320,307,103 |
| 共有2進カード | 100 / 100 | 537,650,741.23 | 53,765,074,123 | 495,820,214 | 544,632,419 |

- 同一seedの勝 / 分 / 敗: `100 / 0 / 0`
- 平均Score: 基準解の約1.70倍
- 100ケースすべて公式testerで正常終了
- strict warning付きコンパイル: 警告なし
- AddressSanitizer + UndefinedBehaviorSanitizer: seed 0、42、99で異常なし
- sanitizer時の公式Score: `540,127,553`、`538,820,731`、`538,584,619`

公式testerの計測単位では各ケースの実行時間はすべて0.00秒でした。

## 合法性の確認ポイント

- `50 + 27 x 3 + 29 x 5 + 32 x 7 = 500` 枚を必ず出力します。
- 各山には専用の土台カードをちょうど1枚置きます。
- 各調整カードは高々1山にしか割り当てません。
- 不足修理後と最終出力前に、各種類の使用枚数を上限以下に保ちます。
- 余ったカードは割当先0として捨てます。
