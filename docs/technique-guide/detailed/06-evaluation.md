# 06. 評価関数・代理目的

[詳細編の目次](README.md) · [用語](GLOSSARY.md) · [出典一覧](SOURCES.md)

評価関数は、探索が何を良い候補だと判断するかを決めます。公式得点だけで進みにくい場合、将来の余地や不均衡を補助評価にできます。ただし代理評価が良いことと、本来の得点が良いことは区別します。

説明用の小例と、提出コードで確認した具体例を分けて記載しています。適用効果は未測定で、検算と練習はこれから確かめるための課題です。

## D129. 容量超過と平準化の代理目的

同じ合計長でも、一部へ集中すると容量を超えやすくなります。二乗和は大きな値の偏りを強く罰します。

長さ5,5の二乗和は50、長さ2,8では68です。上限超過への罰則も加えると、平均的な平準化と、越えてはいけない長さを別々に評価できます。

<a id="example-23751222-05"></a>
### コードでの具体例：列長の二乗と上限超過を罰する

列長の二乗項と、n+最大単語長-2を越えた線形項を連結長へ追加する。

**適用条件・落とし穴。** 行へ収まりやすい解を誘導する代理目的。公式得点とは同一でない。

**検算と練習。** 代理値の改善が実被覆数へつながるか測る。

## D130. 期待値に係数を掛ける採否

将来の代替費用を推定し、現在確定できる選択の費用と比べます。係数は判断を採用寄り・保留寄りへずらします。

現在費用100に0.95を掛けると、比較上は95になります。この補正で不確実性を扱う設計ですが、最適な意思決定を保証する式ではありません。

<a id="example-27880973-05"></a>
### コードでの具体例：代替接続閾値の平均に対して現在辺を比較する

代替接続不能は上限Xとして集計し、平均値と現在辺長×0.95を比較する。

**適用条件・落とし穴。** サンプル評価を採否へ変換する際の余裕係数。最適性の保証ではない。

**検算と練習。** 係数と上限打切りの変更で費用・接続失敗率がどう動くか確認する。

出典: [AHC007 / 提出 27880973](https://atcoder.jp/contests/ahc007/submissions/27880973) · `sum versus Q*l[i]*0.95` · L85–L101。 [収録情報](SOURCES.md#submission-27880973)

## D131. 初回到達の期待得点

1回目の到達だけに価値があるなら、到達後の確率を分布から取り除かないと、同じ成功を何度も数えてしまいます。

時刻3に0.2、時刻4に新たに0.1到達したなら、成功確率は0.3です。時刻3の0.2を残して再加点しないよう、到達を吸収として扱います。

<a id="example-30423648-04"></a>
### コードでの具体例：目標に着いた確率を得点化して分布から除く

到達質量を時刻重み付きで加点し、目標セルの質量を0へ戻して再加点を防ぐ。

**適用条件・落とし穴。** 初回成功で終了する確率過程の評価へ使う。

**検算と練習。** 同じ質量が複数時刻で二重加点されないことを確認する。

## D132. 段階で代理目的を変える

最終目的だけでは初期の構造を作りにくいとき、先に弱い部分を育てる評価を使います。

長さ20と1の閉路では、長い方を伸ばすより短い方を育てたい局面があります。前半と後半で評価式を切り替えたら、現在値も新しい式で計算し直します。

<a id="example-31233938-04"></a>
### コードでの具体例：短い閉路の底上げ後に長さの積を最大化する

前半は短い方の長さを10倍する評価、後半は二閉路の長さの積へ切り替える。

**適用条件・落とし穴。** 積目的で片側が極端に小さい状態を先に脱する。

**検算と練習。** 段階切替時の評価再計算と各段階の予算比を比較する。

## D133. 移動距離以外のビーム評価

目標までの距離が同じでも、直す順番や途中の通路が違えば完成しやすさは異なります。距離だけに表れない構造を補助評価へ入れます。

完成済みの場所を何度も通らないと空白を運べない候補は、距離和が小さくても手数が増える可能性があります。

<a id="example-32267675-05"></a>
### コードでの具体例：行列順序・完成近傍・空白の到達性も評価する

距離和だけでなく順序ペナルティ、近隣の完成状況、完成セル通過を費用1とする0-1探索の値を加える。

**適用条件・落とし穴。** 距離だけでは見えない解きにくさを代理特徴で表す。重みの効果は実測が必要。

**検算と練習。** 各成分を外す比較と、局所更新後の成分全再計算を行う。

## D134. 分布間の輸送型距離

現在の分布を目標へ近づけるために、どの大きさの要素をどこへ移す必要があるかを費用にします。

サイズ2の不足をサイズ3の余剰で補う場合と、サイズ8から補う場合を同じに扱わない評価です。質量と個数の単位を揃えて集計します。

<a id="example-32961594-04"></a>
### コードでの具体例：不足数の二乗とサイズ差の二乗輸送費を足す

目標と現在の質量を小さい添字から順にマッチさせ、移動量×サイズ差二乗を加える。

**適用条件・落とし穴。** 完全一致数だけでは疎な評価へ、近い分割サイズにも勾配を与える。

**検算と練習。** 目標一致時が0になることと、単一点移動の手計算を比較する。

## D135. 将来価値の加算

今すぐ得られる価値に加え、その選択が次の構築機会をどれだけ残すかを評価します。

同じ1点追加でも、さらに3方向へ伸ばせる点と、行き止まりの点では将来の自由度が違います。将来ボーナスは見込みなので、実際の得点とは分けます。

<a id="example-35264600-04"></a>
### コードでの具体例：外周から伸ばせる余地を追加の重みとして評価する

辺と必要点の条件を満たす境界区間を拾い、RangeWeightの将来重みを現在の点重みに加える。

**適用条件・落とし穴。** 直近得点の低い足場作りを残したいとき。見込み点は確定得点と区別する。

**検算と練習。** 見込み評価と実際の延長後得点の対応を測る。

## D137. 訪問間隔への変換

一定速度で増え、訪問時にリセットされる量は、時刻ごとの更新を足す代わりに訪問間隔から計算できます。

1ずつ増える汚れを4間隔ためるなら、蓄積は0+1+2+3=6です。周期の末尾と先頭の間も1つの間隔として扱います。

<a id="example-48359374-01"></a>
### コードでの具体例：汚れの時刻シミュレーションを三角数の和にする

各セルの前回訪問時刻を周期の前側へずらして初期化し、訪問間隔から三角数×汚れ増加量を足す。

**適用条件・落とし穴。** 周期的な清掃・巡回で待ち時間費用を評価する場合。周期境界の最後と最初の訪問もつなぐ。

**検算と練習。** 素朴な複数周期シミュレーションと分子・平均値を比較する。

## D138. 待ちと寄り道の代理費用

完了時刻だけでは、途中の無駄を区別しにくいことがあります。待ち・迂回・仮置きなどを補助項へ分けます。

同じ時刻に終わる候補でも、あと1件入れる余地がある方を残す狙いです。ただし補助項を強くすると、最終目的が良い候補を逆に落とす可能性があります。

<a id="example-53942556-06"></a>
### コードでの具体例：完了時刻に加えて迂回・仮置き・入出庫進捗を評価する

実移動時間とマンハッタン下界との差、仮置き数、クレーン稼働終了時刻、入出庫進捗を合成する。

**適用条件・落とし穴。** 完了手数だけでは途中状態を比較しにくい計画。各項の尺度と二重評価を点検する。

**検算と練習。** 各補助項を外した比較と、評価順位と完成解の関係を調べる。

## D140. 相補性の評価

似たもの同士より、強い部分が違う組合せを選びたい場合、差の大きな特徴を評価します。

Aが速度に強くBが耐久に強ければ、互いの弱点を補える可能性があります。差が大きいこと自体が利益になるかは、実際の合成規則に依存します。

**検算と練習。** 全差分和、最大値和、上位差分の指標を同じ入力で比較する。

## D142. 仮説の集約距離

複数の仮説をまとめるとき、どの量を平均するかで結果が変わります。座標平均は、相反する位置を打ち消す場合があります。

距離2と4の二乗平均平方根は√10で約3.16です。距離の単純平均3とも違い、長い可能性をやや強く反映します。

<a id="example-64611675-04"></a>
### コードでの具体例：座標を平均せず距離二乗を平均してから平方根を取る

整合化した複数の座標配置からペア距離二乗を蓄積し、その平均の平方根を後段の辺コストとする。

**適用条件・落とし穴。** 座標の多峰性を一点平均で潰さない。期待距離そのものではなくRMS距離である点を区別する。

**検算と練習。** 平均座標・平均距離・RMS距離を同じ仮説群で比較する。

## D143. 長期確率の近似

1回の試行で確率pの事象を、独立にn回試すなら、少なくとも1回起こる確率は1−(1−p)^nです。

p=0.1を2回なら0.19です。文字列の重なりのように試行同士が依存する場合、この式は近似となるので、実験で誤差を確かめます。

<a id="example-65957786-02"></a>
### コードでの具体例：文字列の一開始点確率から長期間の出現確率を近似する

定常分布を初期分布とする文字列DPでscを求め、1-(1-sc)^回数で一回以上出る確率を近似する。

**適用条件・落とし穴。** 長い出力の探索用代理評価。重なった文字列出現の独立性や開始直後の過渡は保証されない。

**検算と練習。** 小さい出力長で厳密なオートマトンDPと近似誤差を測る。
