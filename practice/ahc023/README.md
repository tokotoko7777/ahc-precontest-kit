# AHC023 - 固定通路 + 区間最適化

## 考え方

作物を置くたびに到達可能性を調べる代わりに、入口からつながるセルを「通路」として最後まで空けておきます。
栽培に使うセルは必ず通路に隣接させます。すると、どの月でも通路を通って対象セルの隣まで行けるため、植え付けと収穫が安全になります。

通路は次の手順で小さくします。

1. 入口だけを通路にする。
2. まだ通路に隣接していないセルを多く覆えるセルを、通路へ追加する。
3. 全セルが通路または通路の隣になったら、不要な通路セルを一つずつ削除する。
4. ランダム化した構築を繰り返し、栽培セルが最も多い形を残す。

通路を固定すると、空間の問題と作物選択の問題を分離できます。作物 `k` は点数を落とさずに占有期間を最短にするため、月 `S_k` に植えて月 `D_k` に収穫します。

選べる栽培セル数を `C` とすると、どの月も同時に存在する作物を `C` 個以下にする必要があります。月を頂点とした最小費用流に

- 何もしない辺: `t -> t+1`、容量 `C`、費用 `0`
- 作物の辺: `S_k-1 -> D_k`、容量 `1`、費用 `-(D_k-S_k+1)`

を張ることで、固定した `C` セルに対する期間合計の最大値を厳密に求めます。最後に選ばれた区間を開始月順に空いているセルへ割り当てます。
同種の通常問題では `library/min-cost-flow.hpp` を貼り付けて再利用できます。提出用
`main.cpp` には必要部分を直接含めているため、外部headerには依存しません。

## 計算量

- 通路構築: 400 セル上の小さなランダム化貪欲法
- 作物選択: 頂点数 `T+1=101` の最小費用流
- 最後のセル割当: `O(K log C)`

## 使い方

```bash
g++ -std=c++20 -O2 -Wall -Wextra -Wshadow main.cpp -o main
./main < input.txt > output.txt
```

提出時は `main.cpp` だけで動き、外部ヘッダには依存しません。

## 合法になる理由

- 通路セルは入口から連結で、作物を置かない。
- 各栽培セルは通路に隣接する。
- 同じセルの次の作物は、前の作物を収穫した翌月以降にだけ植える。
- 各作物は `S_k` 月に植えるので締切を守る。

したがって、植え付け時も収穫時も対象セルへ到達でき、セルの二重使用もありません。

## 検証メモ

公式ローカルツールの seed 0--9 で、次の3段階を同じ入力で比較しました。

| 段階 | 平均スコア | 最小 | 最大 |
|---|---:|---:|---:|
| BFS 木の葉 + 終了月順の貪欲割当 | 170,947.5 | 98,900 | 261,475 |
| 改善した固定通路 + 終了月順の貪欲割当 | 405,530.0 | 375,225 | 438,850 |
| 改善した固定通路 + 最小費用流 | 549,075.0 | 499,275 | 597,100 |

最終版のseed別スコアは次の通りです。

```text
508825 552950 569900 597100 517075
550150 581450 577275 499275 536750
```

- 基準解から最終版までの平均改善: `+221.20%`
- seed 0--9: 全ケース合法
- 通常版の実行時間: 約0.83--1.14秒（検証環境）
- 反復数を減らした検証用ビルドでseed 0--99: 全100ケース合法、平均541,562.25
- `-Wall -Wextra -Wshadow -Wconversion -pedantic -Werror`: 警告なし
- ASan + UBSan: seed 0, 3で異常なし

比較専用のコンパイルオプションとして、`AHC023_SIMPLE_BASELINE` はBFS木の基準通路、`AHC023_GREEDY_SCHEDULE` は貪欲な作物割当、`AHC023_SHORT_VERIFY` は通路探索の反復数を減らした版を選びます。通常の提出では、どれも指定しません。
