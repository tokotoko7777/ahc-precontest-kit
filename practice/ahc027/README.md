# AHC027 - 汚れの緊急度で行き先を選ぶ巡回清掃

## 考え方

同じ経路を繰り返すと、あるセルを清掃してから次に清掃するまでの間隔を `g` として、その区間でたまる汚れの合計は

```text
d * (0 + 1 + ... + (g - 1)) = d * g * (g - 1) / 2
```

です。したがって、汚れやすいセルほど短い間隔で訪れる必要があります。

移動制約をいったん無視すると、セル `v` の優先度を

```text
d[v] * (最後に訪れてからの時間)^2
```

とする方法は、理想的な訪問頻度 `sqrt(d[v])` に対応します。この実装では壁による移動時間も考えて、現在位置からの距離で優先度を割ります。

手順は次の通りです。

1. 全セルを始点とするBFSを行い、セル間の最短距離を求める。
2. `d * (経過時間 + 移動時間)^2 / (移動時間 + 1)` が最大のセルを次の目的地にする。
3. 最短路が複数あるときは、途中で最も汚れがたまっているセルを通る向きを選ぶ。
4. 長い移動では4、8、16歩ごとに目的地を選び直す候補も作る。
5. 長さと先読み係数が異なる5本の閉路を作り、問題の式で目的値を正確に再計算して最良を選ぶ。
6. 低い `d` のセルへの `A -> B -> A` という往復を削った候補も評価する。

最初の18,000歩は状態を安定させるための準備運転として出力しません。その後 `(0,0)` から新しく経路を記録し、最後は最短路で `(0,0)` へ戻ります。

AHC027については参照した知識コーパスに代表提出の人手レビューがありませんでした。上の方法は、公式の採点式と、別の巡回問題で確認された「最短路表」「複数候補」「差分を意識した局所変更」から独自に組み立てたものです。

## 合法になる理由

- 移動は入力から作ったグラフの辺だけを使うので、壁を通らない。
- 目的地への移動と最後の帰還はBFS距離が1減る隣接セルだけを選ぶ。
- 記録は `(0,0)` から始まり、最後も必ず `(0,0)` になる。
- 通常版は97,000歩を目安にし、帰還を含めても99,990歩以下になるよう確認する。
- 万一、準備運転後の経路で未訪問セルがあれば、全セルを訪れるDFS往復路へ切り替える。
- 往復削除は `A -> B -> A` の2手だけを消すため、削除前後の接続は壊れない。各セルの最後の出現は削除しない。

## 計算量

セル数を `V=N^2`、通路辺数を `E`、出力長を `L` とします。

- 全点間距離: `O(VE)` 時間、`O(V^2)` メモリ
- 1本の経路生成: 目的地を選び直す回数を `Q` として `O(QV + L)`
- 正確な評価と往復削除: 1候補あたり `O(V + L)`

`V <= 1600` なので、距離は `uint16_t` で保持しています。
同じ前計算だけ使いたい場合は、距離型を選べる `library/all-pairs-bfs.hpp` を自分の
`main.cpp` へ貼り付けられます。提出用の本ファイルには必要部分を直接含めています。

## 使い方

```bash
g++ -std=c++20 -O2 -Wall -Wextra -Wshadow main.cpp -o main
./main < input.txt > output.txt
```

提出時は `main.cpp` だけで動き、外部ヘッダには依存しません。

## 検証メモ

公式ローカルツール v2 のseed 0--9で、同じ入力を3段階で比較しました。AHC027は小さい方が良いスコアです。

| 段階 | 平均スコア | 基準解比 |
|---|---:|---:|
| DFS木の全辺を往復 | 13,629,819.9 | - |
| 緊急度による単一候補 | 6,183,728.4 | -54.63% |
| 5候補 + 目的地再評価 + 往復整理 | 6,165,032.3 | -54.77% |

最終版のseed別スコアと実行時間は次の通りです。

| seed | スコア | 実行時間（秒） |
|---:|---:|---:|
| 0 | 1,579,199 | 0.22 |
| 1 | 6,872,096 | 0.38 |
| 2 | 1,903,955 | 0.24 |
| 3 | 5,103,382 | 0.70 |
| 4 | 8,718,246 | 0.61 |
| 5 | 14,929,409 | 0.61 |
| 6 | 4,627,543 | 0.22 |
| 7 | 4,010,974 | 0.36 |
| 8 | 7,952,441 | 0.51 |
| 9 | 5,953,078 | 0.53 |

- seed 0--9: 最終版は全10ケース合法、DFS基準解に10勝0敗
- `AHC027_SHORT_VERIFY` 版: seed 0--99の全100ケース合法、平均10,766,224.28
- 通常版のseed 0--9実行時間: 平均0.438秒、最大0.70秒（検証環境）
- `N=39,40` の5ケースも通常版で合法、実行時間0.85--1.02秒
- `-Wall -Wextra -Wshadow -Wconversion -pedantic -Werror`: 警告なし
- ASan + UBSan: seed 0, 3で異常なし

比較・検証専用のコンパイルオプションは次の通りです。通常の提出では指定しません。

- `AHC027_DFS_BASELINE`: DFS往復だけを出力
- `AHC027_SINGLE_POLICY`: 最初の緊急度候補だけを使用
- `AHC027_SHORT_VERIFY`: 100ケース合法性確認用に準備運転と出力長を短縮
