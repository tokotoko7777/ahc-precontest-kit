# AHC001 practice

公式問題: [A - AtCoder Ad](https://atcoder.jp/contests/ahc001/tasks/ahc001_a)

`main.cpp` だけで提出できる、過去AHCを使ったライブラリ実戦例です。

## 使用したパーツ

- `BatchedTimer`
- `Random`
- `AxisAlignedRectangle`

パーツはローカルヘッダとして参照せず、`main.cpp` の上部へ直接貼っています。

## 独自解法

最初に10000×10000の盤面全体を持ち、希望点の集合を縦または横に二分します。
二つの領域の面積比が、そこに含む会社の希望面積比へ近くなる切断を優先し、
1領域に1社だけ残るまで再帰的に分割します。

- 希望点と希望点の間だけで切るので、各担当領域は必ず自社の点を含む
- 担当領域同士は重ならないため、その内側の広告も必ず合法
- 各分割では面積比誤差の小さい候補を上位10件に絞る
- 最良候補だけで作る初期解に加え、上位候補から選ぶランダム多点スタートを行う
- 最後に各担当領域内で、希望面積へ最も近い縦横サイズを全探索する

全長方形を相互に衝突判定しながら動かす代わりに、先に「絶対に重ならない担当領域」を
決めるのが要点です。多点スタート中は24幅だけ調べる近似評価を使い、最終解だけ幅を
最大10000通り調べることで、探索回数と仕上げ精度を両立します。

## この練習で追加した汎用パーツ

`axis-aligned-rectangle.hpp` を追加しました。座標型を選べる半開矩形で、幅、高さ、
面積、点包含、正の面積での重なりを判定できます。辺が接するだけなら重なりません。

## 公式ツールでの確認

公式配布のseed 0〜9で全矩形の境界・点包含・非重複を確認しました。

- 不正出力・重なり: 0ケース
- 平均スコア: 955418224.20
- 最小スコア: 935815381
- 最大スコア: 991212435

以前の1×1矩形からの単調拡張版は同じ10ケースで平均877858829.60点でした。
再帰分割版は平均で約8.8%改善しました。

## 注意

- 上位解法のコードは移植せず、面積比を使う独自の単純な再帰分割として実装しています。
- 軸平行の再帰分割で表せない領域の譲り合いと、分割後の境界移動は行いません。
- 実時間で多点スタート回数が変わるため、同じ入力でも得点は多少変動します。
- AHC069の解答・ベンチマークとは無関係です。
