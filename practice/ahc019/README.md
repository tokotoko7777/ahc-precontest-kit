# AHC019 A - Silhouette Puzzle

公式問題: <https://atcoder.jp/contests/ahc019/tasks/ahc019_a>

`main.cpp` だけで提出できる、合法性を優先した解答例です。外部の `.hpp` や自作
namespace は使っていません。この問題の評価値は**小さいほど良い**ことに注意してください。

## 使い方

```bash
g++ -std=c++17 -O2 -Wall -Wextra main.cpp -o main
./main < input.txt > output.txt
```

AtCoder へは `main.cpp` をそのまま提出できます。

ローカルで短く動作確認したい場合は、探索時間をミリ秒で上書きできます。

```bash
g++ -std=c++17 -O2 -DTIME_LIMIT_MS=200 main.cpp -o main
```

`-DUNIT_BASELINE` を付けると、探索を行わず、必要最小数の単位ブロックだけで埋める
比較用の安全解になります。

## 問題を簡単に言うと

2組の正面・右面シルエットから2個の立体を作ります。同じ番号を両方で使う場合、その部品は
回転と平行移動で完全に一致しなければなりません。

部品が片側にしかないと、その体積がそのまま評価値へ加算されます。両側で共有できれば、
体積 `v` の部品の寄与は `1 / v` です。したがって、大きな共通部品を作ることが重要です。

## 解法

### 1. 置いてよいボクセルを作る

座標 `(x, y, z)` に置ける条件は単純です。

```text
正面シルエット[z][x] == 1
かつ
右面シルエット[z][y] == 1
```

この条件を満たす全ボクセルを、2個の立体について別々に列挙します。許可された場所に置く限り、
シルエットへ余計な `1` が現れることはありません。

### 2. 2個の立体を同時に重ねる

立方体の向きは鏡映を除く24通りです。各回転と平行移動について、立体1の許可ボクセル `p` と
立体2の許可ボクセル `R(p) + t` が両方存在する場所を集めます。

その重なりの6近傍連結成分は、次を同時に満たします。

- 両方のシルエット内にある。
- 各部品が面で連結している。
- 2個の部品は回転 `R` と平行移動 `t` で一致する。

したがって、連結成分をそのまま共通部品として採用できます。平行移動は、許可ボクセルの組を
アンカーにした広域sampleと、立方体中心付近の局所sampleを混ぜています。同じ変換はhashで
二度調べません。

### 3. 残りを何個のボクセルで埋められるかを評価する

高さ `z` ごとに、まだ覆っていない正面の `x` の数を `X`、右面の `y` の数を `Y` とします。
両者は完全二部グラフの辺を1本置くように同時に覆えるため、必要なボクセル数は
`max(X, Y)` です。

候補部品を置く前後でこの値を比較し、

```text
減らせた残余ボクセル数 - 1 / 部品体積
```

が最大の候補を貪欲に採用します。採用済み部品と重なった候補は捨てず、空いている連結成分へ
分割して再利用します。投影の被覆状態は各行を16-bit maskで持つため、候補評価で3次元盤面を
再走査しません。

### 4. 最初の選択だけを変える multi-start

大きな部品を最初に誤ると、その後の候補を広く塞ぎます。そこで最初の候補を上位16通りまで
変え、以降は同じ貪欲を実行します。最後に公式目的関数を直接計算し、最良構築だけを残します。

### 5. 残余を安全に埋める

各高さで未充足の `x` と `y` を組にし、`max(X, Y)` 個のボクセルで必ず全投影を覆います。
組み方を複数試し、隣接する2ボクセルが多くなるものを残します。

隣接ペアはすべて回転で一致するドミノです。一方にしか残余ドミノがない場合も、もう一方の
シルエット内の空き場所へドミノを追加すれば、片側だけの体積2から共通部品の `1/2` へ改善
できます。ドミノにできなかった残りは共通の単位ブロックにし、個数差だけを片側部品にします。

## 計算量と高速化

`V = D^3`、調べた変換数を `T`、保持候補数を `C` とすると、候補生成は概ね `O(TV)` です。
`D <= 14` なので、ボクセル番号は16-bit整数に収まります。

- 3次元座標を `x * D^2 + y * D + z` の整数へ変換する。
- 同じ回転・平行移動をhashで除く。
- 候補は初期被覆量で上位5,000個へ絞る。
- 投影被覆を16-bit maskで差分評価する。
- 時刻は候補走査256回ごとに確認する。
- 常に完成済みの最良構築を保存する。

## 制約と今後の改良

これは読みやすさを優先した、候補制限付きmulti-start貪欲です。候補集合全体のbeam searchや、
採用済み部品を一度壊して組み直す探索は入れていません。入力によっては大部品同士の重なりが
強く、最初の16候補だけでは良い組合せへ届かない可能性があります。

発展案は次の通りです。

- 上位数候補を持つ小幅beam search
- 数個の部品を外して残りを再構築するdestroy / repair
- 共通ドミノだけでなく、直線・L字triominoを残余から抽出する後処理
- 採用候補と競合する変換だけを更新する逆index

## 参照した研究メモと独自性

一次情報として公式問題文と公式toolsのcheckerを確認しました。ローカルknowledge corpusは、
構造検索後にKnowledge map、AHC019 Review、および次の3 technique cardだけを参照しました。

- candidate restriction
- incremental evaluation
- time management

AHC019 Reviewで確認済みだった知見は「2立体で同型部品を同時成長させる」「候補集合を探索する」
「残余を後処理する」という構造です。本実装の24回転による重なり連結成分、投影mask評価、
先頭候補multi-start、空き場所へ追加する残余ドミノは、そこから独自に組み立てたものです。
