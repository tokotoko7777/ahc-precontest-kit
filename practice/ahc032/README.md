# AHC032 - 確定セルを使う局所列挙ビーム

## 重要な性質

スタンプの左上位置を `(p, q)` とします。位置を左上から順に処理すると、`(p, q)` で押すスタンプを決めた後、セル `(p, q)` は以後のスタンプでは変化しません。

この「確定セル」を一つずつ評価へ移すことで、81 マス全体を一度に探索する必要がなくなります。
右上、左下、右下から走査しても同じ性質が成り立つため、4 方向を全て試します。

## 同じ位置で押すスタンプを列挙する

同じ位置での加算順序は結果に影響しません。そのため、20 種類から重複を許して 0～3 枚選ぶ組合せを最初に全列挙します。

各走査位置では次の処理を行います。

1. 現在の各ビーム状態へ、0～3 枚の組合せを適用する。
2. 新しく確定するセルの値を確定得点へ加える。
3. 評価上位 80 状態だけを残す。

評価値は、序盤では確定済みセルを重視し、終盤へ近づくほど未確定セルの現在値も本来の重みへ近づけます。
使用回数は、49 個の走査位置へ `K=81` 回を均等配分した目標値の ±1 に制限します。これにより、序盤だけで回数を使い切る状態や、終盤で回数が足りなくなる状態を避けます。

## ビーム後の改善

ビーム後は公式得点そのものを使います。

- 余った回数には、盤面全体の増分が最大の操作を追加する。
- 操作を一つランダムな操作へ置換する焼きなましを行う。
- 最後に各操作を一度外し、`20 * 7 * 7 = 980` 通りの置換先を全て比較する。

1 回の全置換走査でも調べるセル数は `81 * 980 * 9` 程度です。全候補が悪い場合は、その操作を削除することも許します。

## 合法になる理由

- 列挙するスタンプ番号は常に `0..19`。
- 左上位置は常に `0..6` の盤面内。
- ビーム中は使用回数を `K` 以下に制限する。
- 後処理は操作の置換または削除だけで、操作数を増やさない。

したがって、出力は必ず81回以下の合法な操作列です。

## 使い方

```bash
g++ -std=c++20 -O2 -pipe -Wall -Wextra -Wshadow main.cpp -o main
./main < input.txt > output.txt
```

提出時は `main.cpp` だけで動き、ローカルヘッダには依存しません。

検証用の単純基準解も同じソースから作れます。

```bash
# 毎回、盤面全体の即時増分が最大の操作だけを選ぶ
g++ -std=c++20 -O2 -DAHC032_BASELINE main.cpp -o main-baseline

# 幅10の短時間確認版
g++ -std=c++20 -O2 -DLOCAL_SHORT_TIME main.cpp -o main-short
```

## 計算量

0～3枚のスタンプ組合せ数を `C`、ビーム幅を `B` とすると、ビーム部分はおおよそ
`O(4 * 49 * B * C * 9)` です。
候補は上位 `B` 個だけをヒープへ保持するため、全候補盤面を保存しません。

## 公式ツールでの検証

公式ローカルツールの seed 0--9 を同じ入力集合で比較しました。

| 方法 | 平均点 | 最小 | 最大 |
|---|---:|---:|---:|
| 即時増分最大の単純貪欲 | 63,048,909,260.4 | 61,156,022,105 | 65,995,747,533 |
| 4方向ビーム + 後処理 | **73,487,381,446.5** | 72,859,088,956 | 74,699,633,642 |

完成版の seed 0--9 の点数は
`74699633642, 73000413626, 73460375919, 73656434035, 72859088956, 72981388942, 73349462945, 73302967385, 73827228939, 73736820076`
でした。単純基準解に全 10 ケースで勝ち、平均は約 16.6% 改善しました。

- 通常版: seed 0--9 が全て合法、典型 wall time 1.75 秒、最大常駐メモリ約 4.5 MiB
- 幅10版: seed 0--99 が全て合法、平均 71,885,549,025.13 点、範囲 70,595,459,656--73,287,976,432
- `-Wall -Wextra -Wshadow -Wconversion -pedantic`: 警告なし
- AddressSanitizer + UndefinedBehaviorSanitizer: seed 0, 73 で指摘なし

幅10版の平均は別の100ケース集合に対する値なので、通常版の seed 0--9 平均との直接比較には使っていません。
