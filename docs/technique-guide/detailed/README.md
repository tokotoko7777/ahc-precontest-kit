## 読み進め方

初めて読む場合は、状態表現 → 初期解 → 近傍 → 評価 → 差分更新の順がおすすめです。探索がすでに動いている場合は、候補制限・前計算・高速化・時間予算から、今いちばん時間を使う部分を選んで読めます。

状態は今の答え、近傍は1回で試す変更、受理はその変更を採用する判断です。最大化のスコアは大きいほど良く、最小化の費用は小さいほど良いものとして説明します。両者の符号を取り違えないよう、各具体例の目的を確認してください。

## 練習するとき

1. 小例を手計算し、何を固定して何を変えたか説明する。
2. 適用条件が成立しない反例を1つ作る。
3. 小さな独立実装と全再計算を比較し、正しさを確かめる。
4. 同じ入力群・時間予算で導入前後を比較し、効果と失敗条件を記録する。

診断の章には未使用分岐や型の問題など、検証対象として取り上げた項目もあります。全てをそのまま採用するための推奨リストとしては扱わないでください。
