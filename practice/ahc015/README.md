# AHC015 practice

公式問題: [A - Halloween Party](https://atcoder.jp/contests/ahc015/tasks/ahc015_a)

`main.cpp` だけで提出できる、未来位置がランダムなオンライン盤面操作の練習例です。

## 問題の要点

10×10盤面へ3種類の飴が1個ずつ置かれます。種類の順番は最初に全て分かりますが、置かれる
空cellは各ターンまで分かりません。1個受け取るたび、盤面を上下左右のどれかへ必ず傾けます。

最後の同色4近傍連結成分の大きさを `s` とすると、分子は `sum(s*s)` です。大きな同色
clusterを作るほど二乗で得をします。

## 解法

### 1. 盤面操作と得点を小さな関数へ分ける

- `place_by_rank`: p番目の空cellへ飴を置く
- `tilt_board`: 1方向へ全て詰めた新盤面を返す
- `component_square_sum`: 固定長stackで同色連結成分を数える

盤面は `array<unsigned char, 100>` なので、仮想未来ごとのコピーに動的確保はありません。

### 2. 4候補を同じ未来で比較する

現在の4方向それぞれについて、未来の置き場所を複数回ランダム生成し、最大30ターン先まで
進めます。同じsampleの「何番目の空cellか」という乱数列を4候補で共有します。候補ごとに
別乱数を使う場合より、未来の偶然差ではなく最初の方向差を比べやすくなります。

仮想未来内では、各方向を1手試して連結成分二乗和が大きい方向を選びます。種類1を上、
種類2を下、種類3を左へ寄せる弱い位置評価も加え、まだ連結得点がほぼ同じ序盤を補助します。

### 3. 実盤面だけを更新する

rollout用盤面は全てコピーです。平均価値が最大の最初の1方向だけを実盤面へ適用し、`endl`で
出力とflushを同時に行います。次の配置番号は出力後にしか届かないため、flushは必須です。

## 読む時の目印

- `partial_board_value`: 公式分子を最優先した途中盤面評価
- `quick_policy_direction`: 仮想未来の軽い1手方策
- `choose_by_rollout`: 共通乱数による4方向比較
- `SIMPLE_POLICY`: rolloutなしの色別固定方向との比較用macro

## 計算量

sample数を `S`、先読み長を `H` とすると1ターンはおよそ `O(4*S*H*4*100)`です。
盤面サイズと上限を固定し、BFS用stackも使い回せる大きさの配列にしています。

## 公式ローカルツールでの確認

[公式ローカルツール](https://img.atcoder.jp/ahc015/b639c75d.zip)で採点しました。

- seed 0〜19: 全20ケースで100行を出力し、形式エラー0件
- 20ケース平均得点: 574,645.3
- 最小得点: 409,694
- 最大得点: 750,147
- seed 0〜9の固定色別方向版: 平均263,415.8
- 同じseed 0〜9のrollout版: 平均606,551.5（約130%改善）
- 通常版seed 0のsolver実行時間: 約1.13秒

`-Wall -Wextra -Wshadow -pedantic` で警告なしです。ASan・UBSanを同時に有効にした
seed 0でも100ターン完走し、公式ビジュアライザで合法性を確認しました。

## 注意

- rolloutは未来位置の分布が公式どおり一様であることを利用しています。
- 100個目の後の傾きは得点へ影響しませんが、実装を単純にするため1文字出力します。公式
  ビジュアライザは得点に使う最初の99文字だけを適用します。
- 研究資料の共通乱数rolloutという知見を基にした独自C++実装で、第三者コードの転載では
  ありません。
