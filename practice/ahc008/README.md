# AHC008 practice

公式問題: [A - Territory](https://atcoder.jp/contests/ahc008/tasks/ahc008_a)

`main.cpp` だけで提出できる、300ターンの対話と安全な壁設置を練習する例です。

## 問題の要点

30×30の部屋に10〜20匹のペットと5〜10人の人がいます。人は毎ターン、移動、隣接
マスの壁化、待機のどれかを行い、その後にペットが動きます。

壁にするマスは、ターン開始時に次の条件を全て満たす必要があります。

- 人もペットも居ない
- 上下左右にペットが居ない
- 盤面内である

最終的な人の連結領域が広いほど得ですが、同じ領域に居るペット1匹ごとに満足度が
半分になります。

## 段階分断方策

複雑な罠を使わず、盤面を縦長の帯へ分けます。壁の本数は、ペットが多いほど帯を細く
する簡単な式で決め、必ず人数以下にします。

処理は4段階です。

1. 各縦壁を複数の連続区間へ分け、人へ割り当てる。
2. 全員が担当区間の開始位置へ移動する。
3. 中央の入口1マスだけ残し、縦壁を並列に建てる。
4. 左から順に入口を閉じ、ペットの少ない瞬間に帯を確定する。

入口では最初はペット0匹を待ち、残りターンが減ると1匹、2匹も許します。最後まで
入口を開けたままにする失敗を避けるためです。最後の壁以外は右側の人が閉じるので、
確保したい帯の入口へ人を集めすぎません。

## 合法性を守る仕組み

- `can_block_cell` が壁設置前にペット・人・隣接ペットを検査する
- そのターンに壁にするマスを `reserved_block` へ先に記録する
- 移動用BFSは既存の壁と予約済み壁の両方を避ける
- 公式から返された全ペットの移動を手元の座標へ反映する
- 人の移動と壁も同じ順序で手元の盤面へ反映する

人同士とペット同士は同じマスに重なれるため、BFSでは壁だけを障害物にしています。

## 読む時の目印

- `make_jobs`: 壁の本数、位置、担当区間を決める
- `first_step_to`: 予約済み壁も避ける固定30×30のBFS
- `PREPARE` / `BUILD_WALLS` / `CLOSE_GATES`: 現在の段階
- `acceptable_pets`: 残り時間に応じて入口閉鎖条件を緩める
- `endl`: 毎ターンの出力をflushする

## 注意

- 高得点解の確率伝播や二入口罠を移植したものではありません。まずWAを出さずに
  状態更新・並列建設・段階分断を理解するための基礎実装です。
- ペットの種類別将来予測は行わず、現在位置だけで入口を閉じます。犬や猫を含む展開では
  待ち方をさらに改善できます。
- 問題固有の同時行動規則が中心なので、新しい共通 `.hpp` は追加していません。
