# AHC002 practice

公式問題: [A - Walking on Tiles](https://atcoder.jp/contests/ahc002/tasks/ahc002_a)

`main.cpp` だけで提出できる、過去AHCを使ったライブラリ実戦例です。

## 問題の要点

50×50の盤面を開始マスから上下左右へ進みます。同じタイルIDは二度使えません。
訪れたマスの点数（0〜99）の合計がそのケースの得点です。制限時間は2秒です。
公式評価は100ケースの得点合計で、1ケースでも不正出力があると提出全体が0点です。

## 使用したパーツ

- `BatchedTimer`
- `Random`
- `SimulatedAnnealing`
- `BestKeeper`

パーツはローカルヘッダとして参照せず、`main.cpp` の上部へ直接貼っています。

## 独自解法

経路をマス番号の `vector<int>`、使用済みタイルを配列で持ちます。

1. 次のマスの点数と、その先へ進める方向数を見るランダム貪欲を何度も実行する。
2. 一番良い経路を焼きなましの初期解にする。
3. 経路の末尾を外し、別のランダム貪欲で作り直す。
4. 短い内部区間を外し、両端を制限付きDFSでつなぎ直す。
5. 探索中の解とは別に、出力用の最高得点経路を保存する。

序盤は長い末尾や区間も作り直し、終盤ほど変更範囲を小さくします。DFSには展開回数の
上限があるため、一つの候補だけに時間を使いすぎません。

## 読む時の目印

- `grow_tail`: 袋小路を避けながら末尾を作る
- `SegmentRepair`: 外した区間をDFSで修復する
- `current_path`: 焼きなましで現在探索している経路
- `best`: 最後に必ず出力できる最高得点経路

この「一部を外して、制約を守る小さな探索で直す」形は、経路や順序の問題で使える
destroy/repair（破壊・再構築）の基本形です。

## 公式入力での確認

公式配布のseed 0〜9を `-O2` で各1回実行し、盤面外移動とタイルID重複がないことを
別チェッカーで確認しました。

- 不正出力: 0ケース
- 平均得点: 56,702.0
- 最小得点: 54,655
- 最大得点: 58,717
- 平均移動回数: 1,062.2

実時間で反復回数が変わるため、同じ入力でも得点は多少変動します。

## 注意

- 公式入力のタイルIDは最大でもマス数未満なので、使用済み配列を2500要素にしています。
- 最高得点コードの移植ではなく、一般的な多点スタート、焼きなまし、破壊・再構築を
  この問題向けに組み直した実装です。
- この練習では新しい汎用ヘッダを増やさず、既存4パーツの組み合わせを試しています。
