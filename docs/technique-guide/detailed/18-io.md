# 18. 入出力・出力保証

[詳細編の目次](README.md) · [用語](GLOSSARY.md) · [出典一覧](SOURCES.md)

探索内で良い状態が見つかっても、正しい形式とタイミングで実行できなければ答えになりません。対話の同期、最新観測の反映、操作列の再生、展開後の上限を最後まで確認します。

説明用の小例と、提出コードで確認した具体例を分けて記載しています。適用効果は未測定で、検算と練習はこれから確かめるための課題です。

## D318. 対話出力の確定

対話形式では、文字列を出力用バッファへ書いただけでは、相手へ届いていない場合があります。

答えを書いた後でflushし、それから次の入力を待ちます。相手も出力を待っていると、flushがないまま両者が待ち続けることがあります。

<a id="example-27880973-06"></a>
### コードでの具体例：各採否を出すたびにflushする

1または0を出力してflushし、次の辺の観測へ進む。

**適用条件・落とし穴。** 逐次観測プロトコルで出力バッファによる待ち合いを防ぐ。

**検算と練習。** ローカルの対話モックで1応答ごとに次入力が解禁されることを確認する。

## D319. 観測後の安全領域更新

相手の移動を受け取った後、その新しい位置から次の行動の合法性を作り直します。

前ターンに空いていたセルへ動物が来たなら、そこや隣接位置への建設条件が変わります。予測上の位置と観測した実際の位置を混ぜないようにします。

<a id="example-29654603-07"></a>
### コードでの具体例：建設禁止セルを人と動物の周囲から毎ターン作る

人の位置と動物の位置・隣接をbusyにし、建設前に判定する。動物の応答を反映して次ターンへ進む。

**適用条件・落とし穴。** 推定上の有利さより先に現在観測に基づく合法性を保証する。

**検算と練習。** 複数人の同時行動と動物隣接の禁止条件をローカル検証する。

出典: [AHC008 / 提出 29654603](https://atcoder.jp/contests/ahc008/submissions/29654603) · `run / busy` · L53–L82, L649–L673。 [収録情報](SOURCES.md#submission-29654603)

## D320. 出力前の再実行

保存した最良操作列を初期状態から再生し、本当に実行できるか最後に確かめます。

購入時に資金が足りなければ待機へ置き換えるような修復もあります。ただし後続の状態と得点が変わるので、修復した列をそのまま再生し続けて確認します。

<a id="example-71725942-06"></a>
### コードでの具体例：最良操作列を再生し資金不足の操作を待機に置き換える

初期状態から最後に全手を再生し、購入不能な操作をNOOPへ修正して出力する。

**適用条件・落とし穴。** 探索状態の不整合に備える最後の整形。修正で目的値が落ちる場合も記録する。

**検算と練習。** 修正件数と整形後のスコアを検査する。

出典: [AHC058 / 提出 71725942](https://atcoder.jp/contests/ahc058/submissions/71725942) · `simulate_full_sanitize_fast` · L366–L397, L946–L952。 [収録情報](SOURCES.md#submission-71725942)

## D321. 展開長上限の扱い

短い命令で長い操作列を展開する場合、命令数と実際の操作数の上限は別です。

残り3操作しか許されない時に5操作のマクロを呼ぶなら、3操作で止まった状態を評価します。マクロ完了後だけが成功でも、実際の出力は成功していません。

<a id="example-76520389-03"></a>
### コードでの具体例：マクロ全体が上限を越える場合は途中までを再評価する

基本操作数がTを越えたら残り操作数分だけ再生し、途中終了時点でも全配送が完了しているか検査する。

**適用条件・落とし穴。** 圧縮した文字数と展開後操作数が異なる出力向け。両方の上限を混同しない。

**検算と練習。** 上限ちょうどと前後1手のマクロを検査する。

出典: [AHC066 / 提出 76520389](https://atcoder.jp/contests/ahc066/submissions/76520389) · `make_cand_after_P / remain` · L1464–L1517。 [収録情報](SOURCES.md#submission-76520389)
