# AHC068 練習解答

`main.cpp` 1個だけで提出できる、C++17 の練習用解答です。独自 namespace や外部ライブラリは使っていません。

## 問題を短く言うと

- `20 x 20` の各マスに、`0` から `399` のカードが1枚ずつあります。
- 最後に、マス `(r, c)` へカード `20*r+c` を置きます。
- `H r c h w` は、壁のない長方形の左半分と右半分を交換します。`w` は偶数です。
- `V r c h w` は、上半分と下半分を交換します。`h` は偶数です。
- 操作は最大 `100000` 回です。

全カードを揃えたときの公式スコアは、操作回数を `T` として

```text
400 + round(1,000,000 * log2(100,000 / T))
```

です。つまり、完成させたうえで操作回数を減らす問題です。

## コンパイルと実行

このフォルダで次を実行します。

```bash
g++ -std=c++17 -O2 -pipe -Wall -Wextra -Wshadow -Wconversion \
    -Wpedantic -Werror main.cpp -o main
./main < input.txt > output.txt
```

最も単純な比較用解法も同じファイルに入っています。

```bash
g++ -std=c++17 -O2 -pipe -DSIMPLE_BASELINE main.cpp -o baseline
./baseline < input.txt > output.txt
```

`-DBASELINE` でも同じ比較用解法になります。

## 比較用解法

まず、壁を通らずに隣接するマスだけで全マスの全域木を作ります。木の葉側から順番に、置きたいカードを隣接 swap だけで目的地へ運び、そのマスを確定します。

確定していないマスは常に連結なので、次のカードを運ぶ道が必ずあります。速くはありませんが、必ず完成するため、メイン解法が時間切れに近づいたときの保険にも使っています。

## メイン解法

### 1. 揃えたマスを二度と触らない

まだ揃えていないマスを「未確定領域」とします。操作に使う長方形は、未確定領域だけに完全に含まれるものに限定します。これで、一度揃えたカードは崩れません。

次に確定するマスは、未確定領域の境界から選びます。ただし、そのマスが関節点なら除きます。関節点を消すと残りが分断されるためです。この判定には Tarjan 法を使っています。

### 2. 長い1回移動をグラフにする

横幅 `2*d` の `H` 操作では、選んだカードを横へ `d` マス動かせます。高さ `2*d` の `V` 操作でも、縦へ `d` マス動かせます。

そこで、「1回の合法操作でカードが移れるマス」を辺にしたマクログラフを作り、目的地までの最少操作経路を BFS で求めます。最悪でも `d=1` の隣接交換が使えるので、未確定領域が連結なら必ず経路があります。

### 3. ほかのカードも良い方向へ動かす

目的カードを同じだけ動かす長方形は、1つとは限りません。たとえば横移動なら、高さを上下へ広げて複数行を同時に交換できます。

合法な長方形を列挙し、その操作後に全カードの「壁グラフ上の目的地までの距離」がどれだけ増減するかを正確に試します。同じ移動なら、合計距離が最も減る長方形を採用します。

### 4. 揃える順番を複数試す

1つの順番だけに決めず、次の5種類を回転・反転した40通りを試します。

- 行ごと
- 蛇行
- 上下の外側から交互
- 上下の外側から交互に蛇行
- 渦巻き

さらに、BFSで最短経路が複数ある場合の辺順も3種類試し、得られた操作列が最も短いものを残します。探索は1.75秒で止め、途中の試行は隣接交換で必ず完成させます。

### 5. 安全な後処理だけ行う

同じ操作を2回すると元に戻ります。間の操作と交換可能だと確認できる場合だけ、この2回を消します。また、同じ横交換を隣り合う行帯へ行った場合など、合法性を確認できるものだけ1つの長方形へまとめます。

圧縮後の最終操作列は初期盤面からもう一度そのまま再生し、全カードが目的位置へ
着くことを `assert` で確認してから出力します。

## なぜ必ず完成するか

次の不変条件を使っています。

1. 未確定領域は連結である。
2. 全ての操作は未確定領域の中だけで行う。
3. 目的カードを目的マスへ置いてから、そのマスを未確定領域から外す。

関節点でないマスだけを外すので、条件1が保たれます。条件1から目的カードまでの隣接経路があり、隣接交換は常に合法なマクロ辺なので、必ず目的マスへ運べます。最後の1マスは、ほかの399枚が正しいため自動的に正しくなります。

## 高速化

- 各マスから横・縦へ一気に動ける区間を、未確定領域が変わるたびに線形時間でまとめて計算
- 長方形内の壁数と確定済みマス数を2次元累積和で `O(1)` 判定
- 盤面とカード位置を同時に差分更新
- 候補操作だけを正確にシミュレーション
- 1.75秒の締切と、各確定マスでBFSする軽量な隣接交換フォールバック

## 参照した知見と注意点

- 問題の操作、制約、スコア式は公式問題文と公式 scorer で確認しました。
- ローカル知識集からは「大きな構造を壊さない順序」「候補制限」「正確な状態更新」という一般的な考え方だけを参考にしました。
- 知識集の AHC068 review は目的関数を「操作面積の合計」と要約していますが、公式実装では「操作回数」です。この部分は根拠として使っていません。
- review にあるビーム探索や過去操作への遡及挿入は、スコア未照合で実装も複雑なため、この初心者向け版には入れていません。
- 外部提出コードは参照・転記していません。連結領域を順に剥がす構築、マクログラフ、候補矩形の評価は、この練習解答用に組み立てたものです。
