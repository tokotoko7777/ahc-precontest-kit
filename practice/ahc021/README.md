# AHC021 practice

公式問題: [A - Pyramid Sorting](https://atcoder.jp/contests/ahc021/tasks/ahc021_a)

`main.cpp` だけで提出できる、過去AHCを使ったライブラリ実戦例です。

## 使用したパーツ

- `Timer`
- `ZobristHash`
- `TreeBeamSearch::step_with_key`

パーツのコードはローカルヘッダとして参照せず、`main.cpp` の上部へ直接貼っています。

## 独自解法

親の数字が子より大きい違反辺だけをswap候補にします。swapした2頂点に接する辺だけを
調べ、次を差分更新します。

- 違反辺の個数
- 違反している値の差の合計
- 大きい数字が下段にあるほど高い高さポテンシャル
- Zobrist hash

各状態から評価上位6手だけを列挙し、幅4のapply/revert型ビームで探索します。
同じZobrist hashへ到達した候補は、評価が最良のものだけ残します。
