## 読むときの共通ルール

「スコア」は大きいほど良い値、「コスト」は小さいほど良い値として使います。両方を同じ式に混ぜると、受理判定や候補の順位が逆転しやすくなります。実装では、まずどちらに統一するか決めてください。

計算量の `N` は問題中の要素数、`K` は残す候補数です。`O(N)` は、おおむね要素数に比例する仕事が必要という意味です。定数倍やメモリ配置によって実時間は変わるので、計算量だけで実装の優劣は決まりません。

各手法の説明は、特定の入力で得点が上がることを保証するものではありません。動作の正しさを確認した後で、同じ入力群を使って比較します。
