# AHC003: 山登りフォーマットで未知の辺長を学ぶ

公式問題: [Shortest Path Queries](https://atcoder.jp/contests/ahc003/tasks/ahc003_a)

[main.cpp](main.cpp)だけで提出できます。ヘッダ展開済みで、ローカルincludeは不要です。
編集用原本は[ahc003_online_fit.cpp](../../examples/search/ahc003_online_fit.cpp)。
提出用と原本＋ヘッダの一致をCIで確認します。

30×30の未知重みグリッドで1000回の経路要求に答え、ノイズ付きの経路総和から学びます。
最短路はDijkstra。未知辺コストのモデルを、**局所探索の基本フォーマットの山登りモード**で更新します。
別のオンライン専用テンプレートは増やしていません。

## 何を書くか

- RegressionProblem::State: 行/列・固定2区間・辺固有の補正係数と、各観測の予測cache。
- Move: 1係数の変更。変更量と、計算済みの改善量を保持。
- observe: 返却された経路総和を履歴へ追加。真の辺長・未来入力は使わない。
- propose_move: 1変数について正則化付き二乗誤差が最小になる変更を作る。
- evaluate_move: 負の誤差の**改善量**を返す。絶対得点ではない。
- apply_move: その係数が関係する観測だけ予測を差分更新。
- TimeBasedAnnealingRunner: 共通の山登り採否・時間・最良State管理。
- planning_costs / shortest_path: 不確実性ボーナス付き辺コストで経路を選ぶ。

1観測につき256試行。行動後はflushし、返却値を読んでから次へ進みます。
係数の登場する観測を逆引きして、毎近傍で全観測を調べないようにしています。

## 限界

- 真の変化点は任意位置ですが、このモデルは中央で固定2分割する近似です。
- 最適化する誤差と経路スコアは別物。1024試行への増加は不採用になりました。
- 上位提出の複数Kalman/MCMCモデルを再現したものではありません。
- 公式提出は行っていません。AHC069の解答・ベンチマークにも触れていません。
