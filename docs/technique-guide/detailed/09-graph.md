# 09. グラフ・経路

[詳細編の目次](README.md) · [用語](GLOSSARY.md) · [出典一覧](SOURCES.md)

元の問題をグラフへ写すと、連結性・最短路・集合の併合として扱える部分が見えてきます。距離の合計と最大辺の重み、局所の連結と全体の連結など、似た言葉の違いに注意して読みます。

説明用の小例と、提出コードで確認した具体例を分けて記載しています。適用効果は未測定で、検算と練習はこれから確かめるための課題です。

## D205. ボトルネック接続閾値

辺を軽い順に加え、2点が初めてつながる重さを調べると、経路上の最大辺を最小にした値が得られます。

A–Bが4、B–Cが7なら、この経路のボトルネックは7です。辺の重みの合計11とは別の尺度なので、最短路距離と混同しません。

<a id="example-27880973-02"></a>
### コードでの具体例：代替経路で両端がつながる重みを測る

軽い未来辺から連結し、現在辺の両端が同成分になる最初の重みを取り出す。

**適用条件・落とし穴。** 候補辺の価値を代替接続の閾値と比較する。全MSTを毎回出力する必要はない。

**検算と練習。** 小グラフの全経路min-max値とDSUによる閾値を比較する。

出典: [AHC007 / 提出 27880973](https://atcoder.jp/contests/ahc007/submissions/27880973) · `scenario union-find` · L75–L89。 [収録情報](SOURCES.md#submission-27880973)

## D206. 異種中継点の活用

目的と同じ種類の点だけを使うより、別種類の点を中継にすると接続を増やせる場合があります。

ただし中継点の追加で得点規則上の損失が出るなら、併合全体の利得を計算します。連結しただけで必ず得になるとは限りません。

<a id="example-34085279-05"></a>
### コードでの具体例：別色PCをハブにして正の利得があるクラスタだけ併合する

相手クラスタごとに最短のハブ接続候補を残し、色ヒストグラムで併合後スコアを計算する。正の増分のみ選び、長さを微小な同点処理に使う。

**適用条件・落とし穴。** 同種接続が基本でも異種を介して得する場合。接続予算2本と経路の占有を都度確認する。

**検算と練習。** ヒストグラム差分と全ペア採点を比較し、ハブが重複使用されないか検査する。

出典: [AHC013 / 提出 34085279](https://atcoder.jp/contests/ahc013/submissions/34085279) · `MergeCluster` · L2568–L2744。 [収録情報](SOURCES.md#submission-34085279)

## D207. 粗いグラフへの縮約

広い格子のすべてを頂点にせず、代表点とその接続で大まかな経路を探します。

20歩ごとの代表点で全体の方向を決め、実際の細かい道は後で扱います。代表点の間隔が粗すぎると、細い通路や地形の変化を見落とします。

<a id="example-39142737-02"></a>
### コードでの具体例：斜めを含む疎な観測点グラフを作る

間隔18の格子と半間隔ずらした点を結び、住宅と既接続水路を近傍から接続する。探索を全4万セルから観測点群へ落とす。

**適用条件・落とし穴。** 空間相関があり大域的な経路選びを先に行う場合。粗い辺は実際の細胞列とは別である。

**検算と練習。** 観測点の間隔別に探索費用、掘削費用、経路の偏りを比較する。

出典: [AHC018 / 提出 39142737](https://atcoder.jp/contests/ahc018/submissions/39142737) · `build_graph` · L217–L251。 [収録情報](SOURCES.md#submission-39142737)

## D208. 局所削除の連結性

1頂点を消した影響は、その頂点に接していた隣接点同士が、別の道でつながるかに現れます。

削除点の隣がA,B,Cなら、残ったグラフで3点が同じ成分か調べます。元の領域が連結であることなど、局所検査を使える前提も必要です。

<a id="example-40290839-04"></a>
### コードでの具体例：削除セルの隣接点から多点BFSし成分の合流を追う

削除予定セルの各隣接点を別ラベルで探索し、ラベルの合流をDSUで管理する。全ラベルが合流した時点で非分断と判定する。

**適用条件・落とし穴。** 1頂点削除の連結性を何度も試す場合。訪問世代と一時的に外したセルの復元が必要。

**検算と練習。** 全体flood fillの判定との一致をランダム形状で検査する。

出典: [AHC019 / 提出 40290839](https://atcoder.jp/contests/ahc019/submissions/40290839) · `Disconnects` · L471–L522。 [収録情報](SOURCES.md#submission-40290839)

<a id="example-45917587-02"></a>
### コードでの具体例：旧色の周辺セルだけを代表点へつなぎ直せるか調べる

色を変えた後、旧色の隣接セル同士の接続をBFSで調べる。追加色は隣接セルからコピーするため、その追加点は元成分に接続する。

**適用条件・落とし穴。** 1セル置換で既存成分を分断しないか調べる場合。旧色が消滅するケースは隣接条件と併せて検査する。

**検算と練習。** 全色の成分数を全走査した結果と照合する。

出典: [AHC024 / 提出 45917587](https://atcoder.jp/contests/ahc024/submissions/45917587) · `is_connected / move` · L46–L66, L130–L157。 [収録情報](SOURCES.md#submission-45917587)

## D209. 経路上の中継点の再利用

新しい接続路を足したら、その終点だけでなく途中の点も、次の接続の起点にできます。

AからBへ伸ばした道がCの近くを通れば、次は途中点からCへ短くつなげます。既存の辺を再使用した場合は、費用を重複して払わないようにします。

<a id="example-42196314-05"></a>
### コードでの具体例：最短路を足す途中の全頂点を新しい接続起点にする

全点対最短路の辺列を保持し、選んだ路上の辺を重複課金せず追加する。通過頂点からも未接続局への候補を更新する。

**適用条件・落とし穴。** 端末集合を結ぶネットワークの近似構築。厳密なSteiner最適化ではない。

**検算と練習。** 辺集合の連結性と費用重複なしを検査し、単純な端末MSTと比較する。

出典: [AHC020 / 提出 42196314](https://atcoder.jp/contests/ahc020/submissions/42196314) · `solve_node2edge` · L1030–L1083, L1348–L1363。 [収録情報](SOURCES.md#submission-42196314)

## D210. 競合集合の統合

資源を共有できるかは、使用する状態集合が重なるかで判定できる場合があります。

群Aが状態{1,3}、群Bが{2,4}を使うなら交差は空です。ビット集合のANDで検査できますが、統合により後続規則が衝突しないかも確認します。

<a id="example-71030207-05"></a>
### コードでの具体例：色を共有する群の使用状態が重複しないかビット集合で調べる

各色群の使用状態集合をANDして競合を判定し、小さい群を大きい群へ移す。セル統合に伴う後続色群の整合も確認する。

**適用条件・落とし穴。** 規則キーが色と状態の積である圧縮向け。単純に同じ動作だけで統合しない。

**検算と練習。** 統合前後で全使用キーの決定性を検査する。

出典: [AHC056 / 提出 71030207](https://atcoder.jp/contests/ahc056/submissions/71030207) · `canMergeColorGroups / mergeColorGroups` · L3453–L3524。 [収録情報](SOURCES.md#submission-71030207)

## D211. 局所表から全体検査へ

安い局所判定で安全が確定する場合だけ早く通し、分からないケースを全体検査へ送ります。

3×3の形だけで削除後もつながると分かれば探索を省けます。局所で分からないことを「危険」と断定せず、必要なら関節点やBFSで詳しく調べます。

<a id="example-78259988-03"></a>
### コードでの具体例：3×3判定で判断できない削除だけ関節点を調べる

局所占有パターンで安全に除去できる場合を表にし、判定できない場合のみ領域全体の関節点情報を作って使う。

**適用条件・落とし穴。** 連結領域の輪郭最適化向け。局所判定が不通過でも即座に不可能とはしない。

**検算と練習。** 全BFS連結判定と照合し、全体検査を省ける割合を測る。

出典: [AHC069 / 提出 78259988](https://atcoder.jp/contests/ahc069/submissions/78259988) · `g_cell_removable / MarkRegionArticulations` · L259–L268, L1991–L2008。 [収録情報](SOURCES.md#submission-78259988)
